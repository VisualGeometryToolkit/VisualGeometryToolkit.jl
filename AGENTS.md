# AGENTS.md

Instructions for coding agents in this repository live in **[CLAUDE.md](CLAUDE.md)**
(workspace-wide) and in each package's own `CLAUDE.md`. Read both before
working in a package. The stack conventions are the files in
[VisualGeometryToolkitCore/conventions/](VisualGeometryToolkitCore/conventions/README.md), in the
order its README gives; CLAUDE.md imports them, so read them too if your agent
does not follow `@` imports.

Where CLAUDE.md names Claude in the commit rules, read it as any agent: never add
an AI co-author line or a "generated with" footer to a commit message.
