PoseLib.jl

Julia bindings to PoseLib, the C++ library of minimal solvers and robust refiners for camera pose estimation by Viktor Larsson and contributors. Every solver and refiner reached from this package is theirs. PoseLib.jl is a thin binding layer and part of the VisualGeometryToolkit stack: its inputs and outputs are the types of VisualGeometryToolkitCore.

Loading the package does two things.

  • It adds a PoseLib backend, PoseLibSolver(), to VisualGeometryToolkitCore's minimal solvers: the four-point homography, the seven-point fundamental matrix, the perspective-three-point (P3P) absolute pose and the five-point essential matrix. It also adds the eight-point essential matrix, essential_dlt. See Minimal solvers.
  • It exports PoseLib's robust Levenberg–Marquardt (LM) refiners: refine_homography, refine_fundamental, refine_relpose and refine_absolute_pose. See Refiners.

Installation

using Pkg
Pkg.add(["PoseLib", "VisualGeometryToolkitCore"])

PoseLib.jl requires Julia 1.12 or later. The C++ library is downloaded prebuilt when the package is installed, so no compiler is needed. For now the binaries cover Linux only; see Platforms and binaries.

Citing

Cite PoseLib, and the original publications of the methods you use (PoseLib's README lists them):

@misc{PoseLib,
  title  = {{PoseLib - Minimal Solvers for Camera Pose Estimation}},
  author = {Viktor Larsson and contributors},
  URL    = {https://github.com/vlarsson/PoseLib},
  year   = {2020}
}

PoseLib.jl is part of VisualGeometryToolkit. Cite the toolkit as well; its CITATION.cff is the source of this entry:

@software{pritts2026vgtk,
  author = {Pritts, James and Sauer, Hendrik},
  title  = {{VisualGeometryToolkit.jl}: Julia Packages for Multiple-View Geometry},
  url    = {https://github.com/VisualGeometryToolkit/VisualGeometryToolkit.jl},
  year   = {2026}
}
