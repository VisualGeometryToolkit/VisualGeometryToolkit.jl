Scoring API

The RANSAC loop scores through VisualGeometryCore's scoring contract; the contract, its derived verbs and the baseline scorers are VisualGeometryCore's and documented here because the loop is built on them. Paper scorers (the Student-t + uniform marginal StudentTUniformScoring) are RansacScoringDoneRight's and are documented there.

The scoring contract

A scorer implements the required verbs; the optional ones default in VisualGeometryCore.

VisualGeometryCore.AbstractScoring — Type
AbstractScoring

A hypothesis score: evaluates a model's residuals and returns a value used for best-so-far gating, the size of the consensus set it implies (for the adaptive stopping rule), and that set's order (for the local optimizer). The contract — scoring_workspace, score!, inlier_count, consensus_order, and the optional verbs with their defaults — is stated in robust/scoring_contract.jl; the RANSAC loop calls only it.

VisualGeometryCore.scoring_workspace — Function
scoring_workspace(scoring, n::Int, d_g::Int) -> W

The scorer's own scratch for up to n points of codimension d_g, built ONCE per composed workspace and reused by every score!. scoring_workspace(buf) reads it back from a ScoreBuffers.

VisualGeometryCore.score! — Function
score!(W, scoring, scores, residuals, n; sample = nothing, bound = -Inf) -> Float64
score!(W, scoring, scores, residuals, problem, θ::Uncertain, n; sample = nothing, bound = -Inf) -> Float64

Score a model from its residuals residuals[1:n] (model-certain), or — a predictive scorer only — from the problem and the model with its covariance (filling residuals with the whitened residuals of the same constraint evaluation). Fills scores[1:n] with the per-point score and caches in W what inlier_count and consensus_order read. sample: the minimal sample's indices (or nothing), whose points are exact by construction. Higher is better.

bound: the score a caller must beat (strictly) for the result to matter. A bounded-sum scorer (score_bound) MAY stop early once the candidate provably cannot exceed it; it then returns a value ≤ bound and its cached state is undefined until the next full score!. The default -Inf never stops early.

VisualGeometryCore.consensus_order — Function
consensus_order(scoring, W) -> AbstractVector{Int}

The order of the points after the most recent score!: its first inlier_count(scoring, W) entries are the consensus set. A view of the scorer's buffer, valid until the next score!.

VisualGeometryCore.is_predictive — Function
is_predictive(scoring) -> Bool

Whether the scorer scores a model WITH its covariance (θ::Uncertain). Default false.

VisualGeometryCore.scored_model — Function
scored_model(scoring, problem, θ, sample) -> θ′ | nothing

The form in which a model is scored: the plain model (default), or for a predictive scorer Uncertain(θ, Σ̃θ) with the covariance of the model fit on the points sample; nothing when there is none (a degenerate sample, which is skipped like a failed solve).

VisualGeometryCore.scale_prior — Function
scale_prior(scoring) -> IGPrior

The scale prior the scorer's consensus scale is fit under. Default JeffreysPrior().

VisualGeometryCore.outlier_halfwidth — Function
outlier_halfwidth(scoring) -> Float64 | nothing

The half-width of the scorer's uniform outlier model, if it has one (the Student-t + uniform posterior weights read it); nothing otherwise (default).

VisualGeometryCore.inlier_threshold — Function
inlier_threshold(scoring, buf::ScoreBuffers) -> Float64

The scorer's decision point for the most recent score! on buf: the residual below which a point is an inlier. A threshold scorer returns its threshold; a scale-free scorer derives one from its consensus set. A local optimizer with no width of its own follows it (loss_at). Only scorers with has_inlier_threshold define it.

VisualGeometryCore.has_inlier_threshold — Function
has_inlier_threshold(::Type{S}) -> Bool

Whether scorer type S defines inlier_threshold — a static trait, false by default, declared true beside the method.

VisualGeometryCore.check_workspace — Function
check_workspace(scoring, W) -> nothing

Refuse, at entry, a workspace built for a different scorer (ArgumentError). The default refuses a workspace the scorer cannot read — no inlier_count(scoring, W) method: another scorer's scoring_workspace built it — and names the scorers it was built for. A scorer whose workspace also depends on its configuration (a prior's tables) adds a method that checks that as well. Called once per entry, never in the inner loop.

Derived verbs and buffers

Stated once in VisualGeometryCore for every scorer: the loop's one scoring path, the consensus set the local optimization starts from, its scale, and the result's soft weights.

VisualGeometryCore.ScoreBuffers — Type
ScoreBuffers{T, W}(n, scoring_ws)

The scoring buffers of one composed workspace, built once and handed to a local optimizer by reference: the residuals (residuals(buf), storage precision T), the per-point scores (scores(buf), Float64 — a derived statistic: squaring a Float32 residual into Float64 is exact), the consensus mask (consensus_mask(buf)), the scorer's workspace (scoring_workspace(buf)) and the evaluation epoch that stamps every ConsensusSet built from them (check_fresh(cs, buf)).

VisualGeometryCore.score_model! — Function
score_model!(buf, scoring, problem, θ; sample = nothing, reuse_residuals = false,
             mask = true, bound = -Inf) -> (S, k)

THE one scoring path of a model on a composed workspace: bump the epoch (every ConsensusSet issued before is stale), compute θ's residuals into residuals(buf) (skipped under reuse_residuals — the caller left them there — for a model-certain scorer), score!, and set the consensus mask (mask = false defers it: consensus_mask! sets it when needed). θ is the SCORED form (scored_model): an Uncertain under a predictive scorer, which then fills the residuals itself. Returns the score and inlier_count.

VisualGeometryCore.ConsensusSet — Type
ConsensusSet(; count, s2, epoch, score = NaN)

The consensus set a local optimizer starts from — the inlier set of the most recent score! on a workspace, as consensus_set returns it: its size k* (count), its scale ŝ² (s2, the Student-t scale of the set under the scorer's prior, consensus_s2), the epoch of the score evaluation that produced it and that evaluation's score (NaN when the producer did not carry it). Construct it by keyword; the field order is not API.

A ConsensusSet describes ONE evaluation: it is valid only while it reflects the MOST RECENT score! on the buffers it was built from. Producers stamp epoch with the buffers' evaluation counter; consumers (local optimizers) must establish that the stamp still equals the current epoch before using it, via check_fresh or is_fresh.

Read it through its accessors, never by field name:

  • inlier_count — count, the set size k*.
  • scale_s2 — s2, the consensus scale ŝ².
  • consensus_score — score, the evaluation's score (NaN: not carried).
  • check_fresh / is_fresh — the epoch stamp, which is only ever meaningful compared against a current epoch, and so is exposed as that comparison rather than as a raw number.
VisualGeometryCore.inlier_count — Function
inlier_count(cs::ConsensusSet) -> Int
inlier_count(scoring, W) -> Int

The size k* of a consensus set; for a scoring and its workspace, the k* of the most recent score! — the statistic that drives the hypergeometric stopping rule.

VisualGeometryCore.consensus_set — Function
consensus_set(scoring, W, residuals; model_dof, d_g, epoch, score = NaN) -> ConsensusSet

The consensus set of the most recent score!: its size inlier_count, its scale consensus_s2 over consensus_order, stamped with epoch, carrying that evaluation's score when the caller has it.

VisualGeometryCore.consensus_s2 — Function
consensus_s2(scoring, residuals, order, k; model_dof, d_g) -> Float64

The Student-t scale ŝ² of the consensus set order[1:k] under the scorer's scale_prior: partition_student_t of its RSS (partition_rss, from the plain residuals). model_dof is the caller's — m + 1 for a local optimizer's consensus set (the scale's extra dof), m for a result's σ̂.

VisualGeometryCore.inlier_probabilities! — Function
inlier_probabilities!(w, scoring, scores, order, k; model_dof, d_g) -> w

Per-point inlier probabilities of the consensus set order[1:k]: under a scorer with an outlier model (outlier_halfwidth a number) the Student-t + uniform posterior of the set's Student-t (posterior_inlier_probs! on the squared per-point scores, under the scorer's prior); otherwise 0/1 membership of order[1:k].

Baseline scorers

MSAC and RANSAC at a threshold. MsacScoring(problem; threshold) is the default scorer of every find_* pipeline.

VisualGeometryCore.MsacScoring — Type
MsacScoring{DG, T}

MSAC at codimension DG: the truncated quadratic 1 − ρ(d², τ²)/τ² at the threshold τ, summed over the residuals (see residual_quality). Constructors as RansacScoring: width-free MsacScoring() / MsacScoring(dg) / MsacScoring(problem), or the loop scorer MsacScoring(dg; threshold = τ).

VisualGeometryCore.RansacScoring — Type
RansacScoring{DG, T}

RANSAC inlier counting at codimension DG: a model's score is the number of residuals below the threshold (see residual_quality).

  • RansacScoring(), RansacScoring(dg), RansacScoring(problem): the width-free grid family (T = Nothing);
  • RansacScoring(dg; threshold = τ), RansacScoring(problem; threshold = τ): the loop scorer at threshold τ (in the problem's residual unit — pixels for the pixel-data problems), T = Float64.
VisualGeometryCore.residual_quality — Function
residual_quality(scoring, d2::Float64, loss_width::Float64) -> Float64

The score contribution of ONE residual with squared value d2 under a loss-width family scoring at loss_width; a model's score is the sum over its residuals, and higher is better:

  • RANSAC: the inlier indicator d² < loss_width² (TLS's weight);
  • MSAC: 1 − ρ(TLSShape(), d², loss_width²)/loss_width².

RansacScoringDoneRight adds the methods of its paper baselines (MLESAC, MAGSAC++, the loss costs). Plain Float64 functions, callable inside a kernel. A non-finite d2 is an outlier and is skipped by every caller; it is not an input.

Scale priors

The prior a scorer's consensus scale is computed under (scale_prior, Jeffreys by default).

VisualGeometryCore.IGPrior — Type
IGPrior(alpha0, beta0)

Inverse-Gamma prior on σ²: π(σ²) ∝ (σ²)^{-(α₀+1)} exp(-β₀/σ²). Conjugate to the Gaussian inlier likelihood, so the marginal reduces to a closed-form sweep update.

The Jeffreys prior π(σ²) ∝ 1/σ² is the limiting α₀ = β₀ = 0 case, built by JeffreysPrior() (or IGPrior()); one struct handles both.

Fields

  • alpha0::Float64 — shape hyperparameter (0 ⇒ Jeffreys)
  • beta0::Float64 — scale hyperparameter (0 ⇒ Jeffreys)
VisualGeometryCore.JeffreysPrior — Function
JeffreysPrior() -> IGPrior

The Jeffreys scale prior π(σ²) ∝ 1/σ²: IGPrior(0.0, 0.0), the default prior of every scale estimator and scorer in the stack. A function returning the value, not a second name of the type — test alpha0 == 0 rather than dispatching on a name.

Weight policies

VisualGeometryCore.AbstractWeightPolicy — Type
AbstractWeightPolicy

A reweighting rule: the nuisance and weight blocks of block_coordinate_descent!. The contract is deliberately minimal — a weight policy promises weights, nothing more:

  • update_nuisance!(policy): refresh whatever nuisance parameters the policy carries — ŝ², ν, the mixing weight π, the Barron shape α — at the current residuals (a no-op for policies that carry none).
  • update_weights!(policy): refresh per-residual weights from the current residuals and those nuisance parameters.

The two run as a pair, in that order, once per outer iteration at a fixed model — see update_nuisance! for the contract.

A weight policy is NOT a likelihood. M-estimation losses with bounded potentials (Welsch, Huber elbows at frozen scale, Barron shape adaptation) have no normalizable density on an unbounded domain — their "objective" is a loss, and only its derivative machinery (ψ(r)/r) is used here. Do not score with a weight policy.

VisualGeometryCore.NormalizedWeightPolicy — Type
NormalizedWeightPolicy <: AbstractWeightPolicy

A weight policy whose underlying objective IS a proper normalized probability model (e.g. the Student-t/uniform mixture posterior, the Gaussian). Only these support likelihood-grade operations: evaluating a comparable objective value, likelihood-monotonicity statements, and use as evidence in a score. The ρ(∞) = ∞ boundary of the theory, as a type.

Local Optimization

A strategy implements VisualGeometryCore's local-optimization contract (lo_workspace, locally_optimize!, returning lo_estimate). The core strategies are NoLocalOptimization and Irls; every other strategy is LocalOptimizationDoneRight's. A width-carrying strategy's loss is resolved by loss_at from its width mode (lo_width, set by with_width): no width follows the scorer's inlier_threshold, ScaleMultiple(m) anchors it at the consensus scale, LossWidth(w) fixes it.

VisualGeometryCore.AbstractLocalOptimization — Type
AbstractLocalOptimization

A local-optimization strategy: refines a seed model on the full measurement set. Strategies are routed by RefitFamily; in-loop IRLS-family strategies additionally plug into the solver via a weight policy (AbstractWeightPolicy).

VisualGeometryCore.lo_workspace — Function
lo_workspace(::Type{P}, ::Type{T}, lo, n::Int) -> L

The local optimizer's own scratch and per-call state for problems of type P with up to n points at storage precision T, built ONCE per composed workspace and reset by each call. Default nothing (an optimizer that needs none).

VisualGeometryCore.locally_optimize! — Function
locally_optimize!(L, lo, problem, θ, cs::ConsensusSet, buf::ScoreBuffers, scoring) -> FitResult

Refine the hypothesis θ of problem with the strategy lo on its workspace L (lo_workspace), seeded by the consensus set cs of the score that just ran on buf. Returns lo_estimate(θ′, retcode; iterations, residuals_current): θ′ === θ when nothing was refit; residuals_current when residuals(buf) holds θ′'s residuals on exit (the loop then skips recomputing them).

VisualGeometryCore.lo_width — Function
lo_width(lo) -> nothing | ScaleMultiple{Float64} | LossWidth{NTuple{2,Float64}}

The width mode of a width-carrying local optimizer: nothing (follow the scorer's inlier_threshold), ScaleMultiple(m) (the loss width m·ŝ at the consensus scale) or LossWidth (an absolute width). The owner of the strategy implements it; a strategy with no width mode (the seed, a self-scaling optimizer) keeps the default missing.

VisualGeometryCore.with_width — Function
with_width(x, w::WidthAxis) -> typeof(x) with the width `w`

The width setter shared by scorings and local optimizations: a scoring rebuilt at a native width (with_width(scoring, OutlierHalfwidth(a))), a local optimizer given an explicit width mode (with_width(lo, ScaleMultiple(m)), with_width(lo, LossWidth(w))). The owner of the type implements it.

VisualGeometryCore.loss_at — Function
loss_at(lo, shape, cs::ConsensusSet, scoring, buf::ScoreBuffers) -> DeployedLoss

THE resolution of a width-carrying local optimizer's loss, statically dispatched on its width mode lo_width:

  • nothing (follow the scorer): deploy(shape, w²; scale_multiple = 1) with w = decision_width(shape, inlier_threshold(scoring, buf)) — the loss's decision point at the scorer's (the identity for TLSShape);
  • ScaleMultiple(m): deploy(shape, ŝ²; scale_multiple = deployed_scale_multiple(lo, shape, m, ŝ², scoring)), ŝ² = max(scale_s2(cs), eps()) — the consensus-anchored width;
  • LossWidth((m₀, s2)): deploy(shape, max(s2, eps()); scale_multiple = m₀) — the absolute width.
VisualGeometryCore.check_composition — Function
check_composition(scoring, lo) -> nothing

Refuse, once at entry, a local optimizer that follows the scorer's threshold (lo_width(lo) === nothing) composed with a scorer that defines none (has_inlier_threshold). A strategy without a width mode is accepted.

VisualGeometryCore.ScaleMultiple — Type
ScaleMultiple()
ScaleMultiple(m::Real)

A width as a multiple of the estimated scale (see WidthAxis). Bare, it is the AXIS (ScaleMultiple() === ScaleMultiple(nothing)); with a value it is a local optimizer's width MODE: the loss width m·ŝ, ŝ the scorer's consensus scale (in the loss's own currency, see deployed_scale_multiple).

VisualGeometryCore.LossWidth — Type
LossWidth()
LossWidth(w::Real)
LossWidth(scale_multiple::Real, s2::Real)

A robust loss's scale parameter, its loss_width (see WidthAxis). Bare, it is the AXIS; with a value it is a local optimizer's ABSOLUTE width mode, stored FACTORED as (scale_multiple, s2) so that the loss deploys at exactly deploy(shape, s2; scale_multiple) — LossWidth(w) is (1.0, w²) (sq_loss_width = 1.0²·w² === w²), and LossWidth(m, s2) keeps the two factors apart for a reader of s2 alone (a GNC entry, Barron's α fit).

RobustVisualGeometry.NoLocalOptimization — Type
NoLocalOptimization <: AbstractLocalOptimization

No local optimization — the candidate model is scored directly without refit. Default for all scoring functions (via default_local_optimization).

RobustVisualGeometry.Irls — Type
Irls{K<:AbstractLossShape} <: AbstractLocalOptimization

STATIC IRLS at a frozen loss width — direct iteratively-reweighted least squares on loss K, no lift, no graduation. Irls{K} is an LO STRATEGY: one instance of VisualGeometryCore's generic block_coordinate_descent! loop, which is not itself "IRLS" (it also runs EM, the half-quadratic lifts and GNC). Runs the posterior-weight iteration (posterior_irls!) — the PosteriorIrlsMethod / PosteriorIrlsState, same weighted refine! M-step (the problem's chart LM), same best-cost tracking and stop rule — with only the per-iteration weight functor swapped per loss:

  • Irls{WelschShape}: wᵢ = exp(−rᵢ²/loss_width²), loss_width = scale_multiple·ŝ (the paper's Welsch-IRLS arm; 1.5 was the pre-anchoring point)
  • Irls{HuberShape}: wᵢ = min(1, loss_width/|rᵢ|), loss_width = scale_multiple·ŝ (the elbow; 1.345 is the classical value) — the static-tail control (influence constant, never vanishing, past the elbow)
  • Irls{GemanMcclureShape}: wᵢ = (loss_width²/(loss_width²+rᵢ²))², loss_width = decision_width(GM, scale_multiple·ŝ) — the GM static-reweighting arm; its scale_multiple is in the half-weight currency (plain_scale_multiple, the one currency table), so one CV grid transfers across the static and lifted mechanisms (half-weight depth of a Welsch point: scale_multiple·√log2)
  • Irls{GaussianShape}: unit weights, no scale and NO scale multiple — plain least squares over all points, the coverage extreme. It takes no scale_multiple; supplying one is an ArgumentError (a width it would silently ignore)

The loss width is frozen at the start of the call, set by the width mode W (VisualGeometryCore's loss_at) — no per-iteration scale refit:

  • scale_multiple = m (ScaleMultiple(m)): m·ŝ at the consensus set's Student-t scale ŝ, in the loss's currency above;
  • loss_width = w (LossWidth(w)): the absolute width w;
  • neither (nothing, the default): the scorer's decision point (inlier_threshold) — MSAC with Irls{TLSShape} refits at MSAC's threshold.

Fields

  • max_iter::Int=25: max IRLS iterations per hypothesis
  • width::W: the width mode, nothing | ScaleMultiple{Float64} | LossWidth{NTuple{2,Float64}}
RobustVisualGeometry.default_local_optimization — Function
default_local_optimization(scoring::AbstractScoring) -> AbstractLocalOptimization

Default local-optimization strategy for a scoring function: NoLocalOptimization().
