IRLS & Posterior Weighting

Generic Block-Coordinate-Descent Loop

The generic loop dispatches on AbstractBlockCoordinateMethod. Concrete methods plug in by extending a small set of interface methods (all declared public): init_state!, update_model!, update_residuals!, update_nuisance!, update_weights!, post_iteration!, stopping_criterion (a VGC StoppingCriterion value, composed with |; a new criterion implements stop_reason), and block_coordinate_result. Every local-optimization strategy in this package plugs into the block_coordinate_descent! loop through this interface, and a new one does the same.

The RANSAC LO refinement uses the loop via PosteriorIrlsMethod (the iteration of Irls, posterior_irls!; downstream, LocalOptimizationDoneRight's Student-t + uniform IRLS). Its model block is a bound, named update — WeightedRefine (the problem's weighted refine!, the default) or KeepModel (the model held: EM of the noise model on fixed residuals, stopping on the mixture NLL) — and its state a PosteriorIrlsState built from a seeded posterior and its residual buffers.

VisualGeometryCore.AbstractBlockCoordinateMethod — Type
AbstractBlockCoordinateMethod

Abstract type for the problem side of block_coordinate_descent!: the model block, its residuals, and the per-iteration bookkeeping.

Each concrete subtype defines extension points:

  • init_state!(method, prob, θ₀) — build the state and compute the initial r/σ/w. It carries ! because a method may fill buffers its own workspace holds (RobustVisualGeometry's posterior IRLS seeds method.ws's residual buffers, which the iterations then read); the method is the mutated argument
  • update_model!(state, method, prob, θ) — the model block: one weighted update of θ (weighted least squares, LM, Newton), or θ unchanged; nothing when there is no update to make (the run stops with :solve_failed)
  • update_residuals!(state, method, prob, θ) — compute residuals + sq_residuals from θ
  • post_iteration!(state, method, prob, θ, iter) — per-iteration bookkeeping (best-tracking, counters the stopping criteria read)
  • stopping_criterion(method) — the method's own StoppingCriterion (default StopNever)
  • block_coordinate_result(state, method, prob, θ, stop_reason, final_iter) — package result
VisualGeometryCore.block_coordinate_descent! — Function
block_coordinate_descent!(likelihood, method, prob, θ₀; max_iter) -> result

Block coordinate descent on a negative log-likelihood, over three blocks:

  • model — update_model! (the method): weighted least squares, LM, Newton, or nothing at all (a fixed-model method such as a seed EM, which returns θ unchanged);
  • nuisance — update_nuisance! (the likelihood): scale, mixing proportion, ν, Barron α, or nothing;
  • weights — update_weights! (the likelihood): EM responsibilities, loss weights, or GNC surrogate weights.

update_residuals! is bookkeeping between the model and nuisance blocks: it recomputes the residuals block from the new model and descends on nothing. One iteration (step_solver!) is one cycle through every block, in the order model → residuals → nuisance → weights, then post_iteration!. See update_nuisance! for why the nuisance block is not named "scale".

Stopping

The run's criterion is

StopWhenSolveFailed() | stopping_criterion(method) | StopAfterIteration(max_iter)

evaluated in that order by stop_solver! after every iteration: a failed model block ends the run at once (:solve_failed, no other block run); otherwise the method's own criterion is read after post_iteration!, and only then the budget — on the last iteration a method's reason wins over :max_iterations. max_iter ≤ 0 runs no iteration. The result is block_coordinate_result(state, method, prob, θ, reason, iterations) with θ the last model the model block produced (θ₀ if none).

Monotonicity

Instances: EM (under the Neal–Hinton free-energy view EM is coordinate ascent on the free energy, i.e. descent on its negative); IRLS / half-quadratic (RobustVisualGeometry's Irls{K} LO strategy is one — the strategy, not this loop); Barron-adaptive; GNC.

"Descent" is on the negative log-likelihood, and monotonicity is each INSTANCE's claim, not the loop's: the best iterate is kept (a method tracks it in post_iteration! with keep_best and returns it from block_coordinate_result), but the loop never rejects a step. An instance proves monotonicity through its post_iteration! trace. GNC is the declared exception — it changes its objective between iterations.

The state of a PosteriorIrlsMethod run: the seeded posterior rws, the residual buffer residuals (the model's residuals at θ₀, refilled by update_residuals!) and the incumbent's best_residuals, with θ₀ the incumbent at cost. RobustVisualGeometry.WeightedRefine — Type
WeightedRefine()

The model update of a PosteriorIrlsMethod that REFITS the model under the current weights: refine!(refine_ws, problem, θ, weights) — the problem's own weighted solve (its chart LM). The RANSAC local optimization's, and the default.

RobustVisualGeometry.KeepModel — Type
KeepModel(tol)

The model update of a PosteriorIrlsMethod that HOLDS the model: it returns θ unchanged, so an iteration moves only the noise model (the nuisance, then the E-step) — EM of the Student-t + uniform mixture on the model's fixed residuals. The iteration's cost is then the mixture negative log-likelihood (mixture_nll), which that EM never raises, and the loop converges once an iteration lowers it by no more than tol relative.

Classifying a held model's residuals

Regression and classification apart: whatever fitted the model, its residuals are FIXED here. The scorer's consensus set — any scorer with a uniform outlier model (outlier_halfwidth), e.g. RansacScoringDoneRight's StudentTUniformScoring — seeds the Student-t + uniform mixture, EM fits it with the model held, and each residual's MAP label is VisualGeometryCore's is_map_inlier of its posterior.

RobustVisualGeometry.fit_residual_mixture — Function
fit_residual_mixture(residuals, scoring; model_dof,
                     config = MixtureEmConfig())
    -> Union{FitResult{PosteriorWeightState, ResidualMixtureMetadata}, Nothing}

Fit the Student-t + uniform mixture to a held model's residuals (unsquared; the residual NORMS of a codimension-2 measurement) and classify each one.

  1. The scorer takes their consensus set — score! of scoring (any scorer with a uniform outlier model, outlier_halfwidth, whose per-point scores are the squared residuals, as a sort-and-sweep scorer's are) at its codimension and scale prior — and the set's Student-t (ŝ² at the residual dof (k* − model_dof)·d_g) seeds the posterior (PosteriorWeightState on the scorer's consensus_order).
  2. EM with the model held — config.model_update must be KeepModel — under VisualGeometryCore's block_coordinate_descent!: each iteration the nuisance parts (config.nuisance) then the E-step, until the mixture NLL stops falling (tol) or config.max_iter.
  3. Each residual's MAP label: inlier iff is_map_inlier of its posterior.

model_dof counts the parameters the held model spent per correspondence (a bundle's free parameters over the codimension, rounded up). Returns nothing when the partition is too thin to carry a scale.

The result: estimate the fitted mixture, a PosteriorWeightState — its s_hat_sq, student_t_dof and inlier_prior, and per residual its posterior inlier_weight(estimate)[i], whose MAP label is VisualGeometryCore's is_inlier(estimate, i) (is_map_inlier of the posterior: the state is a NormalizedWeightPolicy; inlier_mask(estimate) labels them all); rms and n the root-mean-square residual over the MAP inliers and their count, so rms is the reprojection error of record; retcode and iterations the EM's; metadata a ResidualMixtureMetadata.

RobustVisualGeometry.ResidualMixtureMetadata — Type
ResidualMixtureMetadata

The metadata of a fit_residual_mixture result: the mixture's negative log-likelihood nll of the residuals at the fitted noise model (the quantity the EM lowered).

Every default reads the [mixture_em] table of configs/default.toml; mixture_em_from_toml loads a caller's table and config_dict writes one back.

Student-t + Uniform Mixture

The inlier likelihood of the posterior-weight iteration and of direct posterior weighting calls: the predictive Student-t density obtained by marginalising the inlier scale σ² under the scorer's prior (scale_prior, Jeffreys by default), against a uniform outlier density of half-width outlier_halfwidth(scoring).

A VisualGeometryCore PosteriorWeightState is seeded from a consensus set:

  • In the RANSAC loop: consensus_posterior squares the seed model's residuals (already in the score buffers) and seeds (ν₀, ŝ²₀) from the scorer's consensus_order and inlier_count — no re-score, no sort.
  • Residuals only: fit_residual_mixture scores the residuals once with the scorer and seeds from its consensus set. The outlier half-width is the scorer's; a scorer without one is refused (required_outlier_halfwidth).

consensus_s2! gives the consensus set's scale alone — the scale a consensus-anchored loss runs at — for a refiner outside the loop.

PosteriorLikelihood updates the three nuisance parts — the scale, the inlier prior and the Student-t dof — each under its policy: Estimated(), or held at a value (VisualGeometryCore's FixedS2(s2), FixedPrior(π), FixedNu(ν) and ConsensusDof()).

RobustVisualGeometry.PosteriorLikelihood — Type
PosteriorLikelihood(rws::PosteriorWeightState, n::Int;
                    scale_update = Estimated(), prior_update = FixedPrior(inlier_prior(rws)),
                    nu_update = Estimated()) <: NormalizedWeightPolicy

Likelihood adapter for block_coordinate_descent!. Wraps a VisualGeometryCore PosteriorWeightState with its data size n so the generic block_coordinate_descent! loop can call update_nuisance! / update_weights! without problem-specific detail.

The nuisance is a composite block of three parts, each with its own update policy (VisualGeometryCore's): the scale ŝ² (Estimated() or FixedS2(s2)), the inlier prior π (Estimated() or FixedPrior(π)) and the Student-t dof ν (Estimated(), FixedNu(ν) or ConsensusDof()). The defaults are the Student-t + uniform posterior of the RANSAC local optimization: ŝ² and ν estimated, π held at the seeded state's own value (1/2). A held part takes its value at the first nuisance update.

RobustVisualGeometry.consensus_posterior — Function
consensus_posterior(L::LoBuffers, problem, cs::ConsensusSet, buf::ScoreBuffers, scoring, a::Float64)
    -> PosteriorWeightState

The Student-t + uniform posterior of the consensus set cs, on the local optimizer's buffers L (its posterior state, re-seeded in place), at the uniform outlier half-width a — the ONE seeding of every local optimization that starts from the posterior (the posterior-weight iteration, posterior_irls!; LocalOptimizationDoneRight's mixture lifts). Freshness contract: cs must come from the most recent score on buf; its consensus order is read from the scorer's workspace. The seed model's residuals are already in buf, so squaring them into the posterior buffer avoids a redundant residuals!() sweep. The Student-t scale contributes one extra DOF on top of the minimal sample size (ν = (k − m)·dg).

RobustVisualGeometry.posterior_irls! — Function
posterior_irls!(likelihood, L::LoBuffers, problem, model, cs::ConsensusSet, buf::ScoreBuffers, scoring,
                a::Float64; max_iter) -> FitResult

THE posterior-weight iteration of every posterior-IRLS local optimization: seeded from the consensus set cs of the score that just ran on buf (its order reused, no fresh sort) at the uniform outlier half-width a, then VisualGeometryCore's block_coordinate_descent! with a PosteriorIrlsMethod on the problem's weighted refit. A strategy contributes only its weight policy, likelihood(rws, n) on the seeded posterior state rws:

  • PosteriorLikelihood: the Student-t + uniform posterior, self-scaling — its seed weights are the posterior's own;
  • any other policy (a frozen-width loss, LossPlainWeights) REPLACES the seed weights before the first solve: its update_nuisance! then update_weights!, and the cost re-seeded under those weights.

The best iterate's residuals are handed back to buf (residuals_current = true), so the loop skips a redundant residuals!() sweep.

required_outlier_halfwidth(scoring) -> Float64

RobustVisualGeometry.consensus_s2! — Function
consensus_s2!(ws::RansacWorkspace, problem, scoring, model) -> Union{Float64, Nothing}

The consensus scale ŝ² of model under scoring: its residuals and score on the workspace's buffers, then the consensus set's Student-t scale at a local optimizer's dof (minimal_sample_size + 1) — the scale a consensus-anchored loss runs at in the native loop (scale_s2(consensus_set(…))), floored at eps.

THE one scale source for engines that cannot run in the native loop (an external refiner's adaptive-width arm): never a loss-width-window plug-in. Returns nothing on a consensus set too thin to carry a scale (k* ≤ m + 1) — the caller bails with no refit call.

Posterior Weighting

Lower-level posterior weighting utilities used by both the RANSAC inner loop and stand-alone EM-style refinement. They are VisualGeometryCore's toolkit (import them from there): spec arguments (log_two_outlier_halfwidth, model_dof, codimension) are supplied explicitly, and the partition is a consensus order and its size k, as a scorer's consensus_order and inlier_count give them.

VisualGeometryCore.posterior_weights! — Function
posterior_weights!(w, sq_residuals, order, k; model_dof, log_two_outlier_halfwidth,
                   codimension = 1, prior = JeffreysPrior())

Student-t posterior weights w[i] = P(inlier | rᵢ) · uᵢ of the hard partition order[1:k] of the squared residuals: the partition's Student-t (partition_student_t under prior: ν = (k − model_dof)·d_g + 2α₀, at least 2, and ŝ² = (RSS + 2β₀)/((k − model_dof)·d_g + 2α₀)) against the uniform outlier support, uᵢ = (ν + d_g)/(ν·ŝ² + r²ᵢ). Per point this is posterior_weight of that StudentTMixture. Fills every entry of w.

VisualGeometryCore.posterior_inlier_probs! — Function
posterior_inlier_probs!(w, sq_residuals, order, k; model_dof, log_two_outlier_halfwidth,
                        codimension = 1, prior = JeffreysPrior())

Posterior inlier probabilities w[i] ∈ [0, 1] of the hard partition order[1:k], without the IRLS weight factor — the same mixture as posterior_weights!, so that is this times uᵢ.

VisualGeometryCore.soft_posterior_weights! — Function
soft_posterior_weights!(w, inlier_posterior, sq_residuals, ν, s_hat_sq, log_two_outlier_halfwidth, n, d_g=1[, inlier_prior=1/2])

E-step: compute posterior inlier probability and combined IRLS weight.

Stores inlier_posterior[i] = P(inlier | r_i) separately for the ν M-step, and w[i] = inlier_posterior[i] · u_i (combined weight for the θ solve).

d_g is the constraint codimension (1 for scalar residuals, 2 for 2D).

The separation is critical: the ν Newton update must use fixed E-step weights (not recomputed from the changing ν), otherwise ν and inlier_posterior couple in a positive feedback loop that drives ν → ∞.

VisualGeometryCore.next_nu — Function
next_nu(ν, sq_residuals, s_hat_sq, w_fixed, n; d_g=1, kwargs...) -> ν_new

M-step: Newton update for ν maximizing the EM Q-function with fixed E-step weights.

Maximizes Q(ν) = Σ wi · log t{dg}(ri; ν, ŝ²) w.r.t. ν, where wi are the fixed posterior inlier probabilities from the E-step (not recomputed), ri² the squared NORM of a d_g-vector residual and ŝ² the per-component scale:

log t_d(r; ν, ŝ²) = logΓ((ν+d)/2) − logΓ(ν/2) − (d/2)·log(νπŝ²) − ((ν+d)/2)·log(1 + z), z = r²/(νŝ²)

∂Q/∂ν = Σ wi · [½ψ((ν+d)/2) − ½ψ(ν/2) − d/(2ν) − ½log(1 + zi) + (ν+d)zi/(2ν(1+zi))]

∂²Q/∂ν² = Σ wi · [¼ψ₁((ν+d)/2) − ¼ψ₁(ν/2) + d/(2ν²) + zi/(2ν(1+zi)) − zi(ν + 2d + d·zi)/(2ν²(1+zi)²)]

with z_i the SCALE-NORMALISED squared residual.

Up to max_newton Newton steps from the current ν, each clamped to [ν_min, ν_max]. Newton is taken only where Q is concave (∂²Q < 0), where its step is uphill; elsewhere the step is geometric, uphill along the gradient — ν ← 2ν if ∂Q/∂ν > 0, ν ← ν/2 otherwise.

VisualGeometryCore.median_seeded_posterior — Function
median_seeded_posterior(sq, n; outlier_halfwidth, codimension = 2, ν = 1e4,
                        prior = IGPrior()) -> PosteriorWeightState

A PosteriorWeightState seeded from the MEDIAN residual, for a caller with no partition to seed from. Every point starts an inlier candidate at the scale ŝ² = median(r²)/median(χ²_d) (floored at eps), with ν large (a near-Gaussian start) and the E-step run once. Allocates its own buffers (sq[1:n] is copied). codimension is 1 or 2; median(χ²_d) is chisq_median.

Scale and Mixture Estimation

The scale fit, the Student-t + uniform mixture and its ECM cycle, and the degrees-of-freedom policies the posterior weighting above draws on. They are VisualGeometryCore's (import them from there).

VisualGeometryCore.fit_scale — Function
fit_scale(prior::IGPrior, rss, dof) -> s2

Fit the squared scale ŝ² as the inverse-gamma MAP, (rss + 2β₀)/(dof + 2α₀).

Returns ŝ², the SQUARED scale — never a linear σ̂.

ŝ² is PER COMPONENT: rss sums squared NORMS of dg-vector residuals, so dof counts components — `νdata = (k − modeldof)·dgfor a hard partition, ordg·Σπᵢin the IRLS M-step (updatescale!). The2α₀/2β₀pseudo-counts make a refinement inherit the scoring prior (β₀floors ŝ² at low inlier counts);IGPrior(0, 0)(Jeffreys) givesrss/dof`.

The first argument is THE ESTIMATOR: IGPrior selects the inverse-gamma MAP, its prior being that estimator's parameters. The residuals are TAKEN as inliers, no initial guess is needed, and no inlier decision is made here.

The result is floored at eps(), so a zero rss under Jeffreys returns eps(), not a NaN. A caller that would rather HOLD its previous scale in that case must test the dof itself at the call site.

VisualGeometryCore.update_scale! — Function
update_scale!(pws, n)

M-step, scale block: overwrite ŝ² from the E-step's weights and the current squared residuals, and nothing else. Call after the residual block fills sq_residuals(pws); the ν block is update_nu!, called after this.

ŝ² is the ECM step of the d_g-variate Student-t with scale ŝ²·I:

ŝ²_new = Σ πᵢ uᵢ rᵢ² / (d_g · Σ πᵢ),     uᵢ = (ν + d_g)/(ν + rᵢ²/ŝ²),

with πᵢ the inlier posteriors and rᵢ² squared NORMS. The E-step's weight is precision-scaled, wᵢ = πᵢ·(ν + d_g)/(νŝ² + rᵢ²) = πᵢuᵢ/ŝ², so the numerator is ŝ²·Σwᵢrᵢ² at the ŝ² that E-step used, and the inverse-gamma prior enters as fit_scale(prior, ŝ²·Σwᵢrᵢ², d_g·Σπᵢ). Returns ŝ².

update_scale!(pws, n, policy) -> ŝ²

The scale block under its update policy. Estimated() is update_scale!(pws, n); FixedS2 holds ŝ².

VisualGeometryCore.partition_student_t — Function
partition_student_t(prior::IGPrior, rss, k; model_dof, codimension = 1) -> (ν, ŝ²)

The Student-t of a hard partition of k points with residual sum of squares rss. It is the scoring marginal's posterior predictive over it under prior, and THE seed of every Student-t in the stack: counted dof ν_data = (k − model_dof)·codimension, then

ν  = max(ν_data + 2α₀, 2),     ŝ² = fit_scale(prior, rss, ν_data).

The ν ≥ 2 clamp keeps the seed's variance finite (a Student-t has one only for ν > 2) at a thin partition, and fit_scale floors the QUOTIENT at eps. One rule for every caller: both PosteriorWeightState seeds, the partition mixture of posterior_weights!/posterior_inlier_probs!, the consensus scale consensus_s2 and a RANSAC result's σ̂. model_dof is the caller's: the sweep's minimal_sample_size for the scoring marginal, one more for a local-optimization seed that also estimates the scale.

VisualGeometryCore.StudentTMixture — Type
StudentTMixture(ν, s_hat_sq, log_two_outlier_halfwidth, d_g[, inlier_prior = 1/2])
StudentTMixture{T}(m::StudentTMixture)

The Student-t inlier + uniform outlier mixture of one E-step, with every per-residual constant precomputed. Its parameters are ν degrees of freedom, squared scale ŝ² = s_hat_sq, outlier support of half-width outlier_halfwidth per axis (log_two_outlier_halfwidth = log(2·outlier_halfwidth), density p_out = (2·outlier_halfwidth)^-d_g), inlier mixing proportion π = inlier_prior. The loggammas are evaluated HERE, once.

An immutable isbits value, so it can be an argument of a KernelAbstractions kernel, and the three scalar functions of it — inlier_posterior, posterior_weight, mixture_nll — are allocation-free plain functions of a squared residual, callable inside a kernel as VGC's ρ is. StudentTMixture{Float32}(m) converts the constants for a Float32 kernel.

These are THE formulas of the mixture: soft_posterior_weights! (the E-step over a buffer) and posterior_weights!/posterior_inlier_probs! (over a partition) build one of these and call the same scalar kernel.

VisualGeometryCore.inlier_posterior — Function
inlier_posterior(m::StudentTMixture, sq_r) -> P(inlier | r)

The posterior probability that a residual with squared norm sq_r is an inlier, π·t / (π·t + (1−π)·p_out). Scalar and kernel-callable.

VisualGeometryCore.posterior_weight — Function
posterior_weight(m::StudentTMixture, sq_r) -> w

The IRLS weight of the mixture at sq_r: P(inlier | r) · (ν + d_g)/(ν·ŝ² + r²), the responsibility times the Student-t's own weight. Scalar and kernel-callable.

VisualGeometryCore.mixture_nll — Function
mixture_nll(m::StudentTMixture, sq_r) -> −log(π·t_ν(r; ŝ²) + (1−π)·p_out)

The negative log-density of the mixture at one residual — the per-point summand of the mixture NLL. Computed against the outlier term in log space, −(log((1−π)p_out) + softplus(log π·t − log((1−π)p_out))), so it is finite for an infinite residual (it is the outlier term's) and for an exact inlier. Scalar and kernel-callable.

mixture_nll(pws::PosteriorWeightState, r, n) -> Float64

The mixture negative log-likelihood Σ_{i ≤ n} −log[π·t_ν(rᵢ; ŝ²) + (1−π)·p_out] of the residuals r[1:n] (UNSQUARED) at the state's current (ν, ŝ², π). It sums the per-point mixture_nll(m, rᵢ²) of StudentTMixture(pws) in Float64. Reads the state; writes nothing.

VisualGeometryCore.mixture_ecm! — Function
mixture_ecm!(pws, r, n)

One ECM cycle of the Student-t + uniform mixture with the mixing proportion ESTIMATED (ν held fixed), from the residuals r[1:n] (unsquared). It squares them into sq_residuals(pws), then runs the E-step (update_weights!), the scale block (update_scale!) and the inlier-prior block (update_inlier_prior!), in that order. Each block is an exact conditional maximisation, so the mixture NLL (mixture_nll) never rises. Returns nothing.

VisualGeometryCore.update_inlier_prior! — Function
update_inlier_prior!(pws, n)

M-step, inlier-prior block: overwrite the mixing proportion π with the mean inlier posterior of the E-step, and nothing else. The mean Σπᵢ/n is clamped to [1e-3, 1 − 1e-3] (the E-step reads it through log((1 − π)/π)). Call after update_weights! filled the posteriors it reads. Returns π.

VisualGeometryCore.ConsensusDof — Type
ConsensusDof()

The update policy of a Student-t dof HELD at the value its consensus seed gave it: the posterior-predictive dof of the scorer's consensus set, ν = 2α₀ + (k* − model_dof)·d_g (partition_student_t, with its ν ≥ 2 floor), where α₀ is the scale prior's shape (0 under Jeffreys). The seed sets it once; the ν block never moves it afterwards.

Why hold it there: a Gaussian whose scale carries an inverse-gamma posterior marginalizes to a Student-t with exactly that dof — ν measures how well the consensus set DETERMINES σ, not the shape of the inlier tail. Estimating ν instead lets the fit trade one for the other: on a contaminated set a heavy inlier tail (ν → 2) absorbs the outliers — the identifiability collapse this policy prevents.

Robust Losses

The loss SHAPES are VisualGeometryCore's (robust/losses.jl; import them from there); they parameterize the loss-parametric LO strategies (the core Irls{K}; downstream, LocalOptimizationDoneRight's HQ{K} and Gnc{S}), so the loss is what carries the objective. A shape is the ρ profile alone — it gains a width only when deploy(shape, ŝ²; scale_multiple) composes the scale and the scale multiple onto it, and it is that deployed loss every function below takes. See the VisualGeometryCore documentation for the full API.

  • AbstractLossShape — abstract supertype
  • GaussianShape — no redescending (plain least squares)
  • HuberShape — linear beyond the elbow
  • CauchyShape — logarithmic penalty (heavy-tailed)
  • WelschShape — exponential penalty; the paper's recipe deploys it as LocalOptimizationDoneRight's HQ{WelschShape} at its cross-validated scale multiples
  • GemanMcclureShape — smooth redescender
  • TLSShape / SmoothTLSShape — truncated least squares, hard and smoothed; Irls{TLSShape}() following the scorer's threshold is every find_* pipeline's default (least squares on the inliers)
  • BarronShape — the α-parameterized family

Irls{K} refuses at construction a shape its mechanism cannot run: BarronShape carries its α — the Barron family runs as LocalOptimizationDoneRight's BarronHQ and BarronAdaptive.

Key functions: weight(shape, s, sq_loss_width) (equivalently lift_weight(loss, s) on a deployed loss) and, for the half-quadratic lift, lift_rho / lift_weight / lift_zblock / lift_cost — each on a DEPLOYED loss, which carries the width, so no scale argument is supplied at the call site. decision_width(shape, decision_threshold) converts the residual at which a decision flips (for a lift arm, the half-weight radius r_½ = scale_multiple·ŝ) into the shape's loss width, and takes the bare shape because that is the conversion that produces a width in the first place.

Retired API

The AbstractLoss family (HuberLoss, CauchyLoss, TukeyLoss, WelschLoss, L2Loss, GemanMcClureLoss, FairLoss) and the AbstractScaleEstimator family (MadScale, WeightedScale, SpatialMadScale) were deleted from VisualGeometryCore along with the file that held them. The loss shapes above replace the first; scale is estimated from the scorer's consensus set (consensus_s2) rather than by a standalone estimator object. (FixedScale is not retired: it is VisualGeometryCore's ScaleInterface label of a strategy deployed at an absolute width, LossWidth.)
