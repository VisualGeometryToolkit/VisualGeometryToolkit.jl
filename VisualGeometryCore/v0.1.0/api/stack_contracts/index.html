Configuration Tags and Stack Contracts API

TagRegistry is the one TOML tag → type map; CONTRACT_GENERICS and the dependency allow-list are what the quality gates (test_quality_gates) check across the stack; the conformance helpers test an implementation of the contracts of the Robust Estimation API page (their methods load with Test).

VisualGeometryCore.TagRegistry — Type
TagRegistry(family::Symbol, suffix::AbstractString, pairs::Pair{<:AbstractString}...;
            retired = (), paths = Regex[])

The ONLY structure a configuration loader uses to map a TOML tag to a type (or, rarely, a value). registry[tag] returns the type; a retired tag throws ArgumentError("tag \"keep\" was renamed \"keep_model\""), and an unknown tag throws an ArgumentError that lists the known tags.

  • family names the family (:local_optimization, :loss) in messages.
  • suffix is the family's common type-name suffix ("Shape" for TLSShape), stripped before the spelling rule; "" for none.
  • pairs are tag => type. The one value that is not a type is nothing, whose tag is "none".
  • retired are old => new renames: the old tag no longer loads, and the error names its successor.
  • paths are the TOML key paths whose string values are tags of this family, matched whole against the dotted path of a value ("lo.arms[2].type"; an array element is [i], counted from 1). The config gate reads them.

The tag rule: a type's tag is snake_case of its name with suffix stripped from its end when present (the whole name otherwise), and nothing is "none". Construction does not check it — a package's load never fails on a spelling — tag_rule_violations does, and the quality gate runs it over every registry constant. A duplicate tag, or a retired tag that is also current, is a construction error.

keys, values, haskey, get, length and iteration (tag => type pairs, in declaration order) cover the current tags only; tag_of is the reverse lookup.

Base.merge — Method
merge(a::TagRegistry, b::TagRegistry...) -> TagRegistry

The registry of one family that two packages share — the core's tags and a downstream package's (merge(RobustVisualGeometry.LO_TAGS, LocalOptimizationDoneRight.LO_TAGS)): every current and retired tag of each, and their key paths. The family and its suffix must agree, and a tag declared by two of them (or current in one and retired in another) is an ArgumentError, as within one registry. There is no global registry: a caller that loads several packages' tags merges them explicitly.

VisualGeometryCore.config_tag_violations — Method
config_tag_violations(registries, config_dirs) -> Vector{String}

Parse every .toml under config_dirs (recursively); every string value at a key path one of the TagRegistrys claims (tag_paths, matched whole) must be a current tag of that registry — not a retired tag and not an unknown one. Each finding is "file:path: message". A file that does not parse is a finding. registries is a collection of registries or of name => registry pairs (the form tag_registries returns).

VisualGeometryCore.expected_tag — Method
expected_tag(registry::TagRegistry, value) -> String

The tag the rule gives value in registry: "none" for nothing, otherwise snake_case of its type name with the registry's suffix stripped from the end when present.

VisualGeometryCore.snake_case — Method
snake_case(name::Symbol) -> String
snake_case(name::AbstractString) -> String

The tag spelling of a CamelCase name, by exactly two rules, then lowercase:

  1. an _ goes before an uppercase letter that follows a lowercase letter or a digit;
  2. an _ goes before the last uppercase letter of an uppercase run when a lowercase letter follows it.

A digit stays with its letters.

snake_case(:FixedS2)              # "fixed_s2"
snake_case(:SmoothTLS)            # "smooth_tls"
snake_case(:WelschHQNewton)       # "welsch_hq_newton"
snake_case(:StudentTUniform)      # "student_t_uniform"
snake_case(:NoLocalOptimization)  # "no_local_optimization"

VisualGeometryCore.tag_of — Method
tag_of(registry::TagRegistry, x) -> String

The writer side of a TagRegistry: the tag of x. x is a registered value (nothing → "none"), a type registered as such, a subtype of a registered type (Irls{2} under a registered Irls; the most specific registered supertype wins) or an instance of one. An ArgumentError when nothing matches.

VisualGeometryCore.tag_rule_violations — Method
tag_rule_violations(registry::TagRegistry) -> Vector{String}

Every way registry breaks the tag rule (see TagRegistry): a tag that is not its value's expected_tag, and a retired tag whose successor is not a current tag. Empty when the registry obeys it.

source
VisualGeometryCore.tag_table_violations — Method
tag_table_violations(dir) -> Vector{String}

A heuristic source scan of the .jl files under dir (a package's src/) for tag tables built outside a TagRegistry: a Dict{String, <:Type}-style table (keyed by a string or symbol, valued by Type, DataType or UnionAll), or a "tag" => SomeType pair — a string literal paired with a CamelCase name that is not called and is not a Base or Core type ("cutoff" => Float32 is a key's converter, not a tag). TagRegistry(...) calls, comments and triple-quoted strings are not scanned. Each finding is "file:line: text", relative to dir.

source
VisualGeometryCore.CONTRACT_GENERICS — Constant
CONTRACT_GENERICS

The generic functions of VisualGeometryCore that another package may add methods to across a package boundary — its extension points. Any stack package may declare its own CONTRACT_GENERICS (a tuple or vector of functions); the quality gate (contract_generic_violations) requires every method a package adds to another stack package's function to land on one of that owner's contracts. Functions owned by Base, Core, the standard library or any package outside the stack are exempt.

source
VisualGeometryCore.contract_generic_violations — Method
contract_generic_violations(M::Module) -> Vector{String}

Every function owned by another loaded stack package (a key of stack_dependencies) that has a method defined in M or one of its submodules but is not in its owner's CONTRACT_GENERICS (a package without one has no contracts). Constructors of another package's types are not counted (Aqua's piracy check covers them). Each finding is "Owner.f (file:line)", located at the first such method.

source
VisualGeometryCore.private_name_violations — Method
private_name_violations(dir, name) -> Vector{String}

A heuristic source scan of the .jl files under dir (a package's src/ and ext/) for names that begin with _ and are reached from another stack package (a key of stack_dependencies other than name): imported (using Pkg: _x, import Pkg.Sub: _x) or accessed qualified (Pkg._x, Pkg.Sub._x, also through a const P = Pkg or import Pkg as P alias). Comments and string literals are not scanned. Each finding is "file:line: Pkg._x", relative to dir.

source
VisualGeometryCore.stack_dependencies — Method
stack_dependencies(; extra = nothing) -> Dict{String, Vector{String}}

The stack's dependency allow-list (configs/stack_dependencies.toml in VisualGeometryCore): each project's name → the stack packages its Project.toml may name. A stack package is any key of this table.

The table lists the published packages and paper projects only. A project kept elsewhere supplies its own row as extra: a path to a TOML file of rows in the same format, or a dictionary name → packages. Extra rows add projects; one that repeats a row of the table is an ArgumentError.

source
VisualGeometryCore.stack_dependency_violations — Method
stack_dependency_violations(project_toml_path, name; extra = nothing) -> Vector{String}

The stack packages the Project.toml at project_toml_path names — in [deps], [weakdeps], [extras] or the test target — that are not in name's row of stack_dependencies (with the extra rows, as there), one "section: Package" per finding. A project absent from the table is an ArgumentError.

VisualGeometryCore.test_constraint_problem — Function
test_constraint_problem(problem, θ)

The constraint-problem protocol on problem at the model θ, as tests: data_size/codimension/minimal_sample_size integers, residuals! type-stable and allocation-free after warm-up and equal to whitened_residual at every point. Implemented by VisualGeometryCoreTestExt.

source
VisualGeometryCore.test_local_optimization_contract — Function
test_local_optimization_contract(lo, problem, θ, scoring; T = Float64, allocations = true)

The local-optimization contract on lo for problem from the hypothesis θ under scoring, as tests: lo_workspace built once, locally_optimize! type-stable, returning a lo_estimate result of the problem's model type, honest about residuals_current (the buffers then hold the refined model's residuals), allocation-free after warm-up (allocations = true). Implemented by VisualGeometryCoreTestExt.

source
VisualGeometryCore.test_scoring_contract — Function
test_scoring_contract(scoring, residuals; n = length(residuals), d_g = 1, sample = nothing)

The scoring contract on scoring over one residual vector, as tests: score! type-stable and allocation-free after warm-up and deterministic; inlier_count in 0:n; consensus_order a permutation of 1:n; the derived consensus_set and consensus_s2 inferred; check_workspace accepting the scorer's own workspace and refusing a foreign one; inlier_threshold a Float64 where has_inlier_threshold; and, for a bounded-sum scorer (score_bound), the early exit tie-safe: a bound the score beats or ties never changes it, and an exit returns a value at or below its bound. Implemented by VisualGeometryCoreTestExt.
