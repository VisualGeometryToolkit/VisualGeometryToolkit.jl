Primitives API

Geometric primitives (circles, ellipses, discs, feature frames, hyperplanes, 3D conics) and their traits and operations. See the Primitives guide.

Primitives and Feature Frames

VisualGeometryToolkitCore.Primitives — Module
Primitives

Geometric primitives submodule for VisualGeometryToolkitCore.

Provides geometric primitive types and operations:

  • Rectangles: Rect constructors from intervals and ranges
  • Conics: Ellipse and Circle types with conic matrix representations
  • Hyperplanes: Lines in 2D, planes in 3D (generalized hyperplanes)
  • Traits: Conic trait system for dispatch
  • Operations: Geometric operations (dilate, intersect, containment)

Main Types

  • Ellipse, Circle, Rect
  • Hyperplane, Line2D, Plane3D
  • ConicTrait, CircleTrait, EllipseTrait

Main Functions

  • dilate, intersects, gradient
  • is_ellipse, classify_conic
  • distance, closest_point, normal, offset

Example

using VisualGeometryToolkitCore.Primitives

ellipse = Ellipse(Point2(0.0, 0.0), 5.0, 3.0, π/4)
circle = Circle(Point2(1.0, 2.0), 2.0)
dilated = dilate(circle, 2.0)

# Hyperplanes
line = Line2D(Point2(0.0, 0.0), Point2(1.0, 1.0))
plane = Plane3D(Point3(0.0, 0.0, 0.0), Vec3(0.0, 0.0, 1.0))
d = distance(line, Point2(1.0, 2.0))

GeometryBasics.Circle — Type
GeometryBasics.Circle(frame::FeatureFrame, r::Real=1.0) -> Circle

Construct a Circle from a FeatureFrame at the r-σ contour.

For isotropic frames (Disc, OrientedDisc), radius = r * σ. For anisotropic frames (EllipticFrame, AffineFrame), radius = r * characteristic_scale (circumscribed circle).

Example

disc = Disc(Point2(100.0, 200.0), 5.0)
circle = Circle(disc, 3.0)  # Circle with radius 15.0 (3σ)

VisualGeometryToolkitCore.Primitives.AffineFrame — Type
AffineFrame{T} <: FeatureFrame{T}

Full affine feature frame with 6 degrees of freedom: translation (2) + general linear (4).

Defines the transformation: x = A·u + center

where A is a general invertible 2×2 matrix. This maps the unit circle to an oriented ellipse in image space. Invariant to full affine transformations.

The extra degree of freedom compared to EllipticFrame is the in-plane rotation that a symmetric matrix cannot represent.

Fields

  • center::Point2{T}: Center position in image coordinates
  • A::SMatrix{2,2,T,4}: Shape matrix (general, not necessarily symmetric)

Decomposition

Any A can be decomposed as A = R(φ)·S where:

  • S is symmetric positive-definite (the "pure shape")
  • R(φ) is an in-plane rotation (the extra DOF)

Example

A = @SMatrix [2.0 0.5; -0.5 1.0]  # general shape matrix
frame = AffineFrame(Point2(100.0, 200.0), A)
T = AffineMap(frame)  # AffineMap: u → A*u + center

See also: EllipticFrame

Ellipse(frame::FeatureFrame, r::Real=1.0) -> Ellipse

Construct an Ellipse from a FeatureFrame at the r-σ contour.

VisualGeometryToolkitCore.Primitives.EllipticFrame — Type
EllipticFrame{T} <: FeatureFrame{T}

Anisotropic feature frame with 5 degrees of freedom: translation (2) + symmetric shape (3).

Defines the transformation: x = S·u + center

where S is a symmetric positive-definite 2×2 matrix (the shape matrix). The moment matrix is M = S·S' = S² (since S is symmetric).

This maps the unit circle to an ellipse in image space. Invariant to affine transformations (up to in-plane rotation).

Fields

  • center::Point2{T}: Center position in image coordinates
  • S::SMatrix{2,2,T,4}: Shape matrix (symmetric positive-definite)

Relationship to Moment Matrix

  • Shape matrix: S (what we store)
  • Moment matrix: M = S² = S·S'
  • To get S from M: S = √M (matrix square root)

Example

S = @SMatrix [2.0 0.5; 0.5 1.0]  # symmetric shape matrix
frame = EllipticFrame(Point2(100.0, 200.0), S)
T = AffineMap(frame)  # AffineMap: u → S*u + center
ellipse = region(frame, 2.0)  # Ellipse at 2σ contour

See also: AffineFrame, Distributions.MvNormal

VisualGeometryToolkitCore.Primitives.OrientedDisc — Type
OrientedDisc{T} <: FeatureFrame{T}

Isotropic feature frame with orientation: 4 degrees of freedom.

Defines the transformation: x = σ·R(θ)·u + center

where R(θ) is a 2D rotation matrix. This maps the unit circle with a marked orientation to an oriented circle in image space. Invariant to full similarity transformations.

Fields

  • center::Point2{T}: Center position in image coordinates
  • σ::T: Characteristic scale
  • θ::T: Dominant orientation in radians (measured from +x axis)

Example

disc = OrientedDisc(Point2(100.0, 200.0), 5.0, π/4)
T = AffineMap(disc)  # AffineMap with rotation

See also: Disc, EllipticFrame

VisualGeometryToolkitCore.Primitives.Paraboloid3D — Type
Paraboloid3D{T,P}

Quadratic surface z = a₀ + b'x + x'Cx over a 2D domain.

The type parameter P encodes the number of free parameters:

  • P=6: Full anisotropic — b and C are free
  • P=4: Isotropic with center — C = cI, b is free
  • P=2: Fixed-center isotropic — C = cI, b = 0

Storage is always the full (a₀, b, C) so the geometric interface (moment_matrix, is_peak, EllipticFrame) works uniformly.

Fields

  • a₀::T: Intercept (peak value)
  • b::SVector{2,T}: Linear gradient
  • C::SMatrix{2,2,T,4}: Quadratic Hessian (neg-def for valid peaks)

Constructors

  • Paraboloid3D(θ::SVector{6}): Full anisotropic {T,6}
  • Paraboloid3D(θ::SVector{4}): Isotropic with center {T,4}
  • Paraboloid3D(θ::SVector{2}): Fixed-center isotropic {T,2}
  • Paraboloid3D(d::Disc, a₀): From detection {T,2}

See also: moment_matrix, is_peak, coeffs, EllipticFrame

Disc{T} <: FeatureFrame{T}

Isotropic feature frame with 3 degrees of freedom: translation (2) + scale (1).

Defines the transformation: x = σ·u + center

This maps the unit circle in canonical space to a circle of radius σ in image space. Invariant to similarity transformations (up to rotation).

VisualGeometryToolkitCore.Primitives.PointFrame — Type
PointFrame{T} <: FeatureFrame{T}

A point feature: a position and nothing else — no scale, no orientation, no shape. What a detector that locates points without a size estimate returns (a corner, the centre of a rotationally symmetric pattern). Its uncertainty is a 2×2 position covariance, Uncertain(PointFrame(c), CovMat{2}(…)), whose Ellipse is the error ellipse — and so is a detection's of one, Ellipse(Attributed(Uncertain(PointFrame(c), Σ), metadata)).

With no scale, a PointFrame has no region, AffineMap or characteristic scale: those methods of the scaled frames do not apply.

Fields

  • center::Point2{T}: the position in image coordinates

Example

julia> using VisualGeometryToolkitCore

julia> p = Uncertain(PointFrame(10.0, 20.0), CovMat{2, Float64}(4.0, 0.0, 0.0, 1.0));

julia> e = Ellipse(p; sigma = 1);   # the 1σ error ellipse

julia> (e.center, e.a, e.b)
([10.0, 20.0], 2.0, 1.0)

See also: Disc

Hyperplanes

VisualGeometryToolkitCore.Primitives.Hyperplane — Type
Hyperplane{M,N,T}

An M-dimensional hyperplane represented by normalized homogeneous coefficients.

The equation a₁x₁ + a₂x₂ + ... + aₘxₘ + d = 0 is stored as [a₁, ..., aₘ, d] where the normal [a₁, ..., aₘ] is automatically normalized to unit length.

Type Parameters

  • M: Ambient space dimension (2 for lines, 3 for planes)
  • N: Number of coefficients (always M+1)
  • T: Coefficient type

Properties

  • normal(h): Unit normal vector [a₁, ..., aₘ]
  • offset(h): Signed distance from origin (-d when normal is unit)

Examples

# 2D line: x - y = 0 (diagonal through origin)
line = Hyperplane(SVector(1.0, -1.0, 0.0))
line = Line2D(1.0, -1.0, 0.0)

# 3D plane: z = 5 (horizontal plane at height 5)
plane = Hyperplane(SVector(0.0, 0.0, 1.0, -5.0))
plane = Plane3D(Point3(0,0,5), Vec3(0,0,1))

# Point-to-hyperplane signed distance
d = distance(line, Point2(1.0, 2.0))

# Closest point on hyperplane (orthogonal projection)
p_closest = closest_point(line, Point2(1.0, 2.0))

VisualGeometryToolkitCore.Primitives.ray_plane_intersection — Method
ray_plane_intersection(plane, origin, dir_x, dir_y, dir_z)
    -> (x, y, z, t)
ray_plane_intersection(plane, o_x, o_y, o_z, dir_x, dir_y, dir_z)
    -> (x, y, z, t)

Broadcasted ray–plane intersection over structure-of-arrays ray bundles: the world-space hit points and ray parameters of the rays origin + t·dir against plane (convention n·x + d = 0). The first form shares one origin::StaticVector{3} across the bundle; the second takes per-ray origin component arrays (finite-aperture cameras, multi-bounce tracers). Rays parallel to the plane divide by zero and produce ±Inf/NaN components — callers mask by validity, the kernel never throws.

The plane is a CONSTANT of the computation: its scalars are extracted once before the broadcast and the extraction is @non_differentiable under the ChainRulesCore extension; gradients flow through origins and directions only.

The Surface a Ray Meets

Two isbits primitives behind one protocol — intersection(s, o, d), normal(s, x), chart(s, x), its inverse surface_point(s, uv) and bounds(s) — generic in the element type (Float32, Float64, ForwardDiff.Dual), allocation-free and usable in a KernelAbstractions kernel. A ray is an origin and a direction in the surface's frame and units, as ray_plane_intersection takes it, and a half-line (t ≥ 0). A Quad is a bounded plane, its intersection ray_plane_intersection's arithmetic bit for bit; a HeightSurface is a thin-plate height field over one, its intersection Newton from the plane hit (four iterations, then on while the update is above rounding). The chart is the DESIGN chart: an in-plane affine (a print's calibration) maps it to the plane, so a pattern lookup uses nominal coordinates. A ray that misses (parallel, behind the origin, outside the rectangle, or not converging) gives NaN. The normal is geometric, the frame's e_u × e_v; flip it against the ray for a camera-facing one. A posed target's primitive is surface(pt) (Imaging Chain and Stereo API).

s = surface(PosedTarget(target, pose))          # a Quad, or a HeightSurface for a height field
t, x = VisualGeometryToolkitCore.intersection(s, o, d)
uv = VisualGeometryToolkitCore.chart(s, x)       # the design coordinates of the hit
VisualGeometryToolkitCore.HeightSurface — Type
HeightSurface(quad, nodes, heights, w, a)
HeightSurface{K, T}(s::HeightSurface)

A height field over a Quad: the points o + m₁ e_u + m₂ e_v + h(m) n for m in the quad's metric plane coordinates, h the thin-plate spline through the K nodal heights at the plane points nodes (metric plane coordinates: a target's calibrated TargetFrame (x, y), which is the design chart when the quad's affine is the identity), with its weights w and affine part a (tps_coefficients; formed once, by whoever builds the surface — surface takes them from the HeightField). Heights are positive along the quad's normal. HeightSurface{K, T}(s) converts the element type.

isbits. intersection is Newton's method on g(t) = (o_ray + t d − o)·n − h(m(o_ray + t d)), started at the plane hit: four iterations unconditionally (RadiometricCamera's count, so a ray that has converged by then is bit-identical to it), then up to sixteen more while the update is above rounding. The update Δt counts as rounding when |Δt|·‖d‖ ≤ 64 eps(T) · (L + |t|‖d‖) (it is then not applied), L the diagonal of bounds in metric plane coordinates (the quad's affine applied to its widths) — a length scale of the surface; the iteration also counts as converged if its last applied update was below √eps(T) · (L + |t|‖d‖) (rounding amplified at grazing incidence). Otherwise the ray is a miss (NaN), as is one whose final surface point is behind the origin or outside bounds. The four iterations alone suffice while the height's slope × tan(incidence) is well below 1 (a print's warp); the continuation covers steep or grazing cases.

normal(s, x) is the unit normal (n − ∂h/∂m₁ e_u − ∂h/∂m₂ e_v) / ‖·‖ from the spline's analytic gradient (tps_gradient), on the side of the quad's normal (geometric; flip it against the ray for a camera-facing one). chart and surface_point are the quad's, the latter lifted by the height.

source
VisualGeometryToolkitCore.Quad — Type
Quad(origin, frame, rect::Rect2, A = I, b = 0)
Quad{T}(q::Quad)

A bounded plane. frame is a right-handed orthonormal 3 × 3 matrix (a rotation) whose columns are the in-plane basis e_u, e_v and the normal n = e_u × e_v; a point with metric plane coordinates m is origin + m₁ e_u + m₂ e_v. The CHART is c with m = A c + b (A an invertible 2 × 2 matrix, inverted once here), and rect is a rectangle in the chart. A left-handed or non-orthonormal frame (to 64 eps of the frame's element type: 1.4e-14 in Float64, 7.6e-6 in Float32), a singular A or a negative width is an ArgumentError. Quad{T}(q) converts the element type (Float32 for a device).

isbits. intersection is ray_plane_intersection's arithmetic, bit for bit, NaN when t < 0 or the hit's chart is outside rect; chart(q, x) = A⁻¹ (m − b); surface_point its inverse; bounds is rect. normal is the GEOMETRIC normal n on either side: a consumer that wants the normal facing the camera flips it against the ray (shading, not geometry). A rigid or affine-calibrated target's surface is a Quad.

Under ChainRules (reverse mode) the plane is a constant of ray_plane_intersection, so a Quad's intersection carries no gradient to its pose; ForwardDiff does.

VisualGeometryToolkitCore.chart — Function
chart(s, x) -> SVector{2}

The chart coordinates (u, v) of the point x of the surface s — the DESIGN chart (for surface(pt), the coordinates of the target's nominal points): the projection of x − o on the in-plane basis of s, then the inverse of the surface's in-plane affine (the print's calibration). VisualGeometryToolkitCore.intersection — Function
intersection(s, o, d) -> (t, x)

Where the ray o + t d, t ≥ 0 (origin o, direction d, both 3-vectors; d need not be unit) meets the surface s: the ray parameter t and the point x. The ray and x are in the surface's frame — for surface(pt) the pose's destination frame F — and its units (metres when the target is physical). A ray that misses — parallel to a plane, hitting behind its origin (t < 0), hitting outside bounds(s), or (a HeightSurface) not converging — returns t and every coordinate of x as NaN, never an error. Methods: Quad (closed form, the arithmetic of ray_plane_intersection) and HeightSurface (Newton). Allocation-free and generic in the element type, so it runs on the GPU path and under ForwardDiff.

source
VisualGeometryToolkitCore.surface — Function
surface(pt::PosedTarget{<:PlanarTarget}) -> Quad | HeightSurface

The surface a ray meets on the posed planar target pt, in the pose's destination frame: the frame of the Quad is the target's TargetFrame placed by pose(pt) (origin its translation, e_u, e_v and the normal the rotation's columns: the normal is TargetFrame +z, heights are positive along it, and nothing is turned towards a viewer). Its CHART is the design chart: the target's in-plane calibration (Rigid or Affine, or a chain of them) is the quad's affine, so chart of a hit is the nominal coordinates it shows. Its rectangle, in that chart, is Rect(board(t)) when the target has a Board, else the design bounding box — either grown by 16 eps of its coordinates, the margin within which PlanarTarget accepts a point on its board, so a ray at a point on the edge is a hit (up to the chart's own rounding).

  • A planar calibration (Rigid, Affine and chains of them) gives a Quad.
  • A HeightField, alone or last in a CalibrationChain after those, gives a HeightSurface over that Quad with the field's nodes and heights (in the calibrated plane coordinates, TargetFrame (x, y)) and the weights the field formed once, when it was built; nothing is solved per ray.
  • An in-plane ThinPlateSpline member is not supported by the ray primitives yet: an ArgumentError naming it.

A physical target (metres) gives a primitive in metres, plain numbers. An uncertain pose or calibration gives its value. A PointTarget has no surface (a MethodError). The kind is chosen by the calibration's type, so a rigid target's ray caster never compiles the height field's Newton loop.

source

VisualGeometryToolkitCore.Primitives.Ellipse — Type
Ellipse{T}

Semantic ellipse representation with center, semi-major axis a, semi-minor axis b, and orientation angle θ in radians.

The constructor automatically ensures a ≥ b by swapping axes and adjusting the angle if needed.

Fields

  • center::Point2{T}: Center coordinates (cx, cy)
  • a::T: Semi-major axis length (always ≥ b)
  • b::T: Semi-minor axis length (always ≤ a)
  • θ::T: Orientation angle in radians [0, π)

Constructors

# Basic constructor with Point2 center
ellipse = Ellipse(Point2(1.0, 2.0), 3.0, 2.0, π/4)

# Constructor with vector center (automatically converted to Point2)
ellipse = Ellipse([1.0, 2.0], 3.0, 2.0, π/4)

# Mixed numeric types are automatically promoted
ellipse = Ellipse([1, 2], 3.0f0, 2, π/4)

Integration with GeometryBasics

# Generate boundary points using GeometryBasics.coordinates
points = GeometryBasics.coordinates(ellipse, 64)

# Access geometric properties
center = GeometryBasics.coordinates(ellipse)  # Returns ellipse.center
major_radius = GeometryBasics.radius(ellipse)  # Returns max(a, b)

VisualGeometryToolkitCore.Primitives.Ellipse — Method
Ellipse(center, A::AbstractMatrix)

Refused: a plain 2×2 matrix is ambiguous — it could be a moment matrix Σ (1σ contour (x-c)ᵀ Σ⁻¹ (x-c) = 1) or an affine "square root" A with Σ = A·A', and for symmetric input the two interpretations silently differ by a squaring. Say which one you mean:

  • moment matrix: Ellipse(center, Symmetric(Σ))
  • affine square root (e.g. Baumberg adaptation): Ellipse(center, Symmetric(A * A'))

VisualGeometryToolkitCore.Primitives.Ellipse — Method
Ellipse(center, Σ::Symmetric) -> Ellipse

Construct an ellipse from a 2×2 moment matrix (symmetric PD). The boundary is the 1σ ellipse: {x : (x-c)ᵀ Σ⁻¹ (x-c) = 1}.

Semi-axes are √λᵢ where λᵢ are eigenvalues of Σ.

Σ = Symmetric([4.0 1.0; 1.0 9.0])

VisualGeometryToolkitCore.Primitives.Ellipse — Method
Ellipse(d::Uncertain{<:AbstractVector, <:Union{CovMat{2}, PrecMat{2}}}; sigma=3) -> Ellipse

The sigma-σ confidence ellipse of an uncertain 2D point: Ellipse(center, Σ::Symmetric) at its covariance cov(d) (a stored precision is inverted once), semi-axes scaled by sigma.

VisualGeometryToolkitCore.classify_conic — Method
classify_conic(Q::Union{HomEllipseMat, HomCircleMat}) -> ConicTrait

Classify a conic matrix and return the appropriate Holy Trait.

Returns one of:

  • EllipseTrait(): Valid ellipse (bounded, non-degenerate)
  • HyperbolaTrait(): Hyperbola (indefinite quadratic form)
  • ParabolaTrait(): Parabola (singular quadratic form)
  • DegenerateTrait(): a point ellipse, an imaginary ellipse, or a conic with no quadratic part (a line). Intersecting line pairs classify as HyperbolaTrait and parallel pairs as ParabolaTrait (their quadratic forms).

Invariant to the conic's scale and sign (a homogeneous conic is defined only up to a nonzero multiplier). A point ellipse is told from a real one by γ, the constant term at the centre, against the rounding of the terms that produce it (|c| + 2|b||centre| + |λ|·|centre|²) magnified by the quadratic block's condition number κ — never against an absolute threshold, which called large or distant ellipses degenerate. The bound was measured: on 20,000 elongated point ellipses (κ up to 1e6) the computed |γ| stays below 0.55·κ·eps of those terms, and the test allows 2·(1 + κ)·eps. An ellipse whose γ is within that noise — thin and far along its minor axis, or small in Float32 — reads degenerate, because the arithmetic cannot tell it from a point.

VisualGeometryToolkitCore.Primitives.Circle3D — Type
Circle3D{T}

A planar circle embedded in 3D space.

Fields

  • center::Point3{T}: Center point of the circle
  • radius::T: Radius of the circle
  • u::Vec3{T}: First basis vector in circle's plane (unit length)
  • v::Vec3{T}: Second basis vector in circle's plane (unit length, perpendicular to u)

Properties

The circle boundary is parameterized as:

p(θ) = center + radius * (cos(θ) * u + sin(θ) * v)

The normal is cross(u, v).

Example

# Circle centered at origin, in xy-plane, radius 3
c3d = Circle3D(Point3(0.0, 0.0, 0.0), 3.0)

# Transform with rigid motion
E = EuclideanMap(R, t)
c3d_transformed = E(c3d)

# Sample boundary point
θ = π/4
p = centroid(c3d) + c3d.radius * (cos(θ) * c3d.u + sin(θ) * c3d.v)

VisualGeometryToolkitCore.Primitives.RegionIntersection — Type
RegionIntersection{A, B}

The intersection a ∩ b of two 2-D regions, held lazily: a point is in it when it is in both (p ∈ s ⟺ p ∈ s.a && p ∈ s.b), and its bounding box is the intersection of the two bounding boxes, Rect2(s) == Rect2(s.a) ∩ Rect2(s.b) (so bbox works on it). Built by Base.intersect (∩) of a Rect, an Ellipse or another intersection, in any order and nesting:

domain = Rect(0, 0, 1920, 1200) ∩ Ellipse(Point2(960.0, 600.0), 700.0, 700.0, 0.0)
Point2(960.0, 100.0) ∈ domain    # true: inside both
Point2(10.0, 10.0) ∈ domain      # false: in the rect, outside the ellipse
Rect2(domain)                    # the rect clipped to the ellipse's box

The identity of ∩ is WholePlane: r ∩ WholePlane() === r (what valid_domain answers for a lens with no limit of its own).

VisualGeometryToolkitCore.Primitives.WholePlane — Type
WholePlane()

The whole plane as a 2-D region: the identity of ∩. Every point is in it (p ∈ WholePlane()), every rectangle lies inside it (r ∈ WholePlane()), and a ∩ WholePlane() === a for any region a (in either order). It has no bounding box: Rect2(WholePlane()) is an ArgumentError. It is what valid_domain answers for a lens with no limit of its own, so Rect(extent) ∩ valid_domain(camera) and Rect(extent) ∈ valid_domain(camera) read the same for every lens, and what imaged_region is given when no image circle is known.
