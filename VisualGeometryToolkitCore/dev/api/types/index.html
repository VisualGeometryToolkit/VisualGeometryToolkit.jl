Core Types API

The core composition and uncertainty types (Attributed, Uncertain, CovMat/PrecMat), the conic and epipolar matrix types, interface stubs, and traits. See the Design: Attributed{V,A} and Stereo Rigs and Uncertainty guides.

VisualGeometryToolkitCore.AbstractDetection — Type
AbstractDetection

Type alias for Attributed{<:Union{FeatureFrame, Uncertain{<:FeatureFrame}}} — any Attributed value whose wrapped value is a FeatureFrame, or a FeatureFrame with its covariance or precision (Uncertain).

This replaces the former abstract type. d isa AbstractDetection is true for any Attributed{V,A} where V <: FeatureFrame or V <: Uncertain{<:FeatureFrame}. Methods on it read the geometry through feature_frame, never d.value, so both kinds behave alike.

VisualGeometryToolkitCore.Attributed — Type
Attributed{V,A}

Generic container composing a value with attributes. Used as the single composition primitive for scored correspondences, detections, deployed losses, uncertain values (Uncertain is the alias Attributed{V, <:Union{CovMat, PrecMat}}) and any "value with metadata" pattern.

Type Parameters

  • V: The value (EllipticFrame, Homography, camera pose, correspondence, etc.)
  • A: Attributes type (a score Float64, a covariance, a struct of attributes, …)

Fields

  • value::V: The wrapped value
  • attributes::A: Associated attributes

Property Access (via @generated getproperty)

  • r.value, r.attributes → direct field access
  • Named fields of A → forwarded from attributes; when A is a statistical form (CovMat/PrecMat, i.e. r is an Uncertain) its storage is not a record: r.matrix names the form itself and nothing else is forwarded from it
  • Other symbols → forwarded to value

Example

sc = Attributed(src => dst, 0.83)   # a scored correspondence
sc.value            # the Pair
sc.attributes       # 0.83
sc.first            # forwarded to value (the Pair)

VisualGeometryToolkitCore.CovMat — Type
CovMat{N,T,M,F} <: StaticMatrix{N,N,T}

N×N covariance matrix Σ = Λ⁻¹ — the covariance counterpart to PrecMat.

Use when the upstream source emits covariance natively (Gaussian process regressors, MVN priors, Kalman-filter outputs). The two forms are interconvertible: inv(Λ) and inv(Σ) (frame-preserving — the representation swaps, the frame does not).

Tensor character and transformation law

Covariance is a (2,0) tensor — both slots contravariant (it PAIRS with two covectors: Σ = E[δx δxᵀ] is built from displacement components). Under a change of coordinates with Jacobian J it pushes forward:

Σ ↦ J Σ Jᵀ

This is the OPPOSITE variance of PrecMat's pullback Λ ↦ J⁻ᵀ Λ J⁻¹, and this covariant/contravariant law pair is exactly the bug surface the frame label exists to check: conjugating with the wrong factor produces a plausible-looking, silently wrong matrix. With labeled frames, propagate through a framed map dispatches to the correct law per type and records the destination frame on the result.

Frame parameter (0.9)

The trailing F <: Frame{N} names the frame the matrix's coordinates live in; every historically-shaped constructor defaults it to UnlabeledFrame{N} (the gradual-typing wildcard — see PrecMat). Storage (the held matrix M, parent(Σ): an SMatrix, SDiagonal or ScaledIdentity) and the StaticArrays interface mirror PrecMat.

Example

Σ = CovMat{2,Float32}(4.0f0, 1.0f0, 1.0f0, 9.0f0)   # 2×2 covariance
e = Ellipse(Uncertain(Point2(100.0, 200.0), Σ); sigma=3)

VisualGeometryToolkitCore.DiagonalCovMat — Type
FullCovMat{N, T, C}, DiagonalCovMat{N, T, C}, IsotropicCovMat{N, T, C}
FullPrecMat{N, T, C}, DiagonalPrecMat{N, T, C}, IsotropicPrecMat{N, T, C}

A covariance (precision) by the matrix it holds: an SMatrix (full), an SDiagonal (CovMat(SDiagonal(σ₁², σ₂²))) or a ScaledIdentity (CovMat(ScaledIdentity{2}(σ²)), CovMat{2}(σ = …)). Arithmetic on the structure is the matrix's own, parent(Σ); on the form itself it sees the full N × N entries and gives an SMatrix.

VisualGeometryToolkitCore.EssentialMat — Type
EssentialMat{T} <: AbstractFundMat{T}

Typed wrapper for a 3×3 essential matrix encoding the calibrated epipolar constraint x̂₂ᵀ E x̂₁ = 0, where x̂ᵢ = Kᵢ⁻¹ uᵢ.

Distinguished from FundMat by the additional E-manifold constraint (σ₁ = σ₂, σ₃ = 0) and by operating on calibrated (K⁻¹-mapped) points. Minimal sample size: 5 (Nistér 2004).

VisualGeometryToolkitCore.FeatureFrame — Type
FeatureFrame{T}

Abstract type for geometric feature frames.

A feature frame defines a transformation from canonical space (unit circle/square) to image space. The transformation encodes the feature's position, scale, and shape.

Concrete subtypes:

  • Disc{T}: 3 DOF - isotropic (translation + uniform scale)
  • OrientedDisc{T}: 4 DOF - isotropic with orientation
  • EllipticFrame{T}: 5 DOF - anisotropic (symmetric shape factor)
  • AffineFrame{T}: 6 DOF - full affine (general shape factor)

Interface

All frames implement:

  • AffineMap(frame) → AffineMap from canonical to image coordinates
  • region(frame, k=1.0) → unitless Circle or Ellipse at the k·σ contour
  • center(frame) → Point2{T} center position
  • Base.inv(frame) → frame with inverted transformation

VisualGeometryToolkitCore.HomEllipseMat — Type
HomEllipseMat{T} <: AbstractHomConicMat{T}

The homogeneous 3×3 matrix of a real, non-degenerate ellipse x̃ᵀ Q x̃ = 0, x̃ = (x, y, 1), stored as its six unique coefficients (Q₁₁, Q₁₂, Q₂₂, Q₁₃, Q₂₃, Q₃₃) — exactly symmetric by storage; indexing returns the full symmetric matrix, and arithmetic on it gives an SMatrix. Built from an Ellipse, a symmetric 3×3 matrix (or its nine entries, column-major) or the six coefficients. A matrix is checked for symmetry (isapprox(Q, Qᵀ; rtol = √eps), its off-diagonal pairs averaged), and check = true checks the class — classify_conic answering EllipseTrait, the same test — with an ArgumentError naming what it is instead; a general conic is a Conic.

VisualGeometryToolkitCore.PrecMat — Type
PrecMat{N,T,M,F} <: StaticMatrix{N,N,T}

N×N information (precision) matrix Λ = Σ⁻¹ for per-observation residual uncertainty. Parametric in N so it sizes to the value dof for any geometric value: 2 for Point2, 3 for Disc, 5 for EllipticFrame, M for Hyperplane{M}, etc. M is the static matrix it holds (parent(Λ)), and its type is the storage: an SMatrix (full), an SDiagonal (diagonal) or a ScaledIdentity (isotropic) — see DiagonalCovMat.

Used as the storage form for sources that emit precision natively (e.g., RoMa v2 dense matcher, factor-graph SLAM backends, any EIV estimator that propagates observation noise to the constraint).

Tensor character and transformation law

Precision is a (0,2) tensor — a bilinear form with two covariant argument slots (it EATS a pair of displacement vectors: the Mahalanobis quadratic rᵀ Λ r). Under a change of coordinates with Jacobian J it pulls back:

Λ ↦ J⁻ᵀ Λ J⁻¹

This is the OPPOSITE variance of CovMat's pushforward Σ ↦ JΣJᵀ, and this covariant/contravariant law pair is exactly the bug surface the frame label exists to check: applying the covariance law to a precision matrix (or vice versa) produces a plausible-looking, silently wrong matrix. With labeled frames, propagate through a framed map dispatches to the correct law per type and records the destination frame on the result.

Frame parameter (0.9)

The trailing F <: Frame{N} names the frame the matrix's coordinates live in (e.g. ImageFrame{:left} for a per-detection pixel precision). Every historically-shaped constructor defaults it to UnlabeledFrame{N} — the gradual-typing wildcard, so pre-0.9 code compiles unchanged and unlabeled matrices propagate uncheckedly. Label with relabel; propagate through a framed map checks the frame against the map's Src and stamps the result with Dst.

Precision vs. covariance

This is distinct from Uncertain's model-side covariance role, which stores parameter uncertainty in covariance form because that case is dominated by Jacobian propagation (J Σ Jᵀ). Per-observation uncertainty on the residual side is dominated by Mahalanobis-style weighting (rᵀΛr), so storing Λ directly avoids inversions on the scoring hot path.

Example

Λ = PrecMat{2,Float32}(1.0f0, 0.0f0, 0.0f0, 1.0f0)   # identity precision
r = SVector(0.3f0, -0.1f0)
maha_sq = dot(r, Λ * r)                              # Mahalanobis²

See also: CovMat, Uncertain, propagate.

VisualGeometryToolkitCore.ScaledIdentity — Type
ScaledIdentity{N}(λ)

The N × N matrix λ·I, stored as the one number λ: the static, sized counterpart of LinearAlgebra.UniformScaling (which has no size), beside StaticArrays' SDiagonal (one number per axis) and SMatrix (every entry). Isotropic: a rotation leaves it unchanged. Isbits; reads as its full matrix. It stays a ScaledIdentity under inv, a scalar factor and a sum with another; a sum with an SDiagonal is an SDiagonal; every other operation gives an SMatrix. The isotropic storage of CovMat / PrecMat and the round GaussianBlur.

VisualGeometryToolkitCore.Uncertain — Type
Uncertain{V, M} = Attributed{V, M}   (M <: Union{CovMat, PrecMat})

A geometric value V with its 2nd-order uncertainty: an Attributed whose attributes are one of the typed matrix wrappers —

  • CovMat{N,T,M} — covariance Σ in parameter space
  • PrecMat{N,T,M} — precision Λ = Σ⁻¹ in parameter/residual space

Uncertain is an alias, not a second struct: one value-with-attributes type carries every value-plus-metadata pattern, and an uncertain value is the one whose attributes are a statistical form. It is constructed ONLY from a CovMat or a PrecMat — a bare matrix or a scalar σ does not say which form is stored, so Uncertain(v, m) with any other m is a MethodError; wrap it as what it is, CovMat(Σ) or PrecMat(Λ). Everything Attributed does it does (u.value, u.attributes, centroid, StructArrays decomposition, index and length forwarding to a vector value), and everything written against Uncertain — cov, prec, geom, propagate, Ellipse — dispatches on exactly these attributes. u.matrix reads the form (getfield(u, :attributes) is the raw field).

The matrix's nominal type tells consumers which form is stored; accessors cov and prec return whichever form the caller asks for, inverting on demand. Each consumer constructs Uncertain with the form it expects to be queried most so the inverse is paid at most once at the boundary, never in the inner loop.

Two roles, one wrapper

  • Observation-side: Uncertain{Point2, PrecMat{2,T,SMatrix{2,2,T,4}}} — a feature detection (e.g. RoMa-v2 dense match) carrying its per-observation precision. Consumed by heteroscedastic Sampson, weighted DLT, IRLS.
  • Model-side: Uncertain{HomographyMat{T}, CovMat{8,T,SMatrix{8,8,T,64}}} — a fitted model carrying its parameter covariance. Consumed by predictive scoring and downstream propagation.

Type Parameters

  • V: The wrapped geometric value (Point2, HomographyMat, Disc, …)
  • M: The matrix wrapper (CovMat{N,T,M} or PrecMat{N,T,M})

Example

# Covariance-side (e.g. propagated parameter uncertainty)
p = Uncertain(Point2(100.0, 200.0), CovMat{2,Float64}(0.1, 0.0, 0.0, 0.2))
cov(p)        # CovMat — stored form, no inversion
prec(p)       # PrecMat — computed via inv(matrix)

# Precision-side (e.g. RoMa per-detection PrecMat)
Λ = PrecMat{2,Float32}(2.0f0, 0.1f0, 0.1f0, 3.0f0)
d = Uncertain(Point2(123.4, 56.7), Λ)
prec(d)       # PrecMat — stored form, no inversion
cov(d)        # CovMat — computed via inv(matrix)
d isa Attributed   # true: the same type as Attributed(Point2(123.4, 56.7), Λ)

# A bare matrix states nothing: wrap it as the form it is
p2 = Uncertain(Point2(100.0, 200.0), CovMat(@SMatrix [0.1 0.0; 0.0 0.2]))
# An isotropic standard deviation σ: the keyword constructor of the form
p3 = Uncertain(Point2(100.0, 200.0), CovMat{2}(σ = 0.5))   # Σ = 0.25·I
Uncertain(Point2(100.0, 200.0), 0.5)   # MethodError: neither a CovMat nor a PrecMat

See also: CovMat, PrecMat, cov, prec.

VisualGeometryToolkitCore.classify_conic — Method
classify_conic(Q::Union{Conic, HomEllipseMat, HomCircleMat}) -> ConicTrait

Classify a conic matrix and return the appropriate Holy Trait.

Returns one of:

  • EllipseTrait(): Valid ellipse (bounded, non-degenerate)
  • HyperbolaTrait(): Hyperbola (indefinite quadratic form)
  • ParabolaTrait(): Parabola (singular quadratic form)
  • DegenerateTrait(): a point ellipse, an imaginary ellipse, or a conic with no quadratic part (a line). Intersecting line pairs classify as HyperbolaTrait and parallel pairs as ParabolaTrait (their quadratic forms).

Invariant to the conic's scale and sign (a homogeneous conic is defined only up to a nonzero multiplier). A point ellipse is told from a real one by γ, the constant term at the centre, against the rounding of the terms that produce it (|c| + 2|b||centre| + |λ|·|centre|²) magnified by the quadratic block's condition number κ — never against an absolute threshold, which called large or distant ellipses degenerate. The bound was measured: on 20,000 elongated point ellipses (κ up to 1e6) the computed |γ| stays below 0.55·κ·eps of those terms, and the test allows 2·(1 + κ)·eps. The test runs in at least Float64 on the coefficients divided by the largest, so a Float32 conic is classified as its stored coefficients define it (a 3 px Float32 ellipse at (1000, 800) is an ellipse; in Float32 arithmetic its γ sank below the noise floor), and neither a huge nor a tiny multiple of a conic overflows or underflows. An ellipse whose γ is within that noise — thin and very far along its minor axis — reads degenerate, because the arithmetic cannot tell it from a point. The checked HomEllipseMat constructor runs this same test, and Ellipse(Q) reads the centre and γ in the same precision.

VisualGeometryToolkitCore.AbstractCamera — Type
AbstractCamera

The one camera type: every camera — an unposed model (CameraModel, a NoncentralSplineModel), a posed camera (PosedCamera) and a bounded one (BoundedCamera) — subtypes it. Whether a camera carries a pose is a trait, is_posed (shared with the targets), not a second type root.

Every camera implements, in the COLMAP pixel frame:

  • project(camera, X) — a 3D point (camera frame for a model, world frame for a posed camera) to its pixel
  • backproject(camera, u) — a pixel to its ray

A posed camera (is_posed(camera) == true) also implements pose(camera) and extrinsics(camera); on an unposed one they are an ArgumentError.

Example

# Code that works with any camera type:
function process(cam::AbstractCamera, points::Vector{Point3})
    pixels = [project(cam, p) for p in points]
    # ...
end

  • scale = σ: a positive, finite noise scale (ScaleGiven);
  • scale = result: an earlier robust result, read by noise_scale (ScaleUpstream; a result that recorded no scale is refused);
  • width = w: a positive, finite loss width. The stage records ScaleNone (its scale is NaN) and the width itself: a width may be cross-validated rather than generative, so no scale is ever backed out of it (w / c), and a downstream stage needs its own scale or width.

Neither, or both, is an ArgumentError naming both keywords. A stage with no robust loss (plain least squares) takes neither, and refuses one it would ignore — that check is the stage's, which knows its loss.

source

Why a fit stopped is its termination record, a ReturnCode and a StopRule in the result's core: see the Termination Record page.

Its per-datum weights in [0, 1] are weights(result), a plain vector; what they mean — and so where inlier_mask(result) cuts them — is the producer type's WeightKind, read by weight_kind (Estimation Interfaces).
