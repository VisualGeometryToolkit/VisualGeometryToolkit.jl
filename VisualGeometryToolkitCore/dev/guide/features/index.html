Feature Detection

Module Moved

Feature detection (scale space, blob detection, affine adaptation, descriptor matching) has been extracted to VisualGeometryToolkitFeatures.jl. Import detect_features, the detector types, scale-space machinery, and match from VisualGeometryToolkitFeatures instead of VisualGeometryToolkitCore.Features.

What remains in VisualGeometryToolkitCore is the geometry that detections are made of, and the composition types that carry them:

  • The feature-frame primitives — Disc, OrientedDisc, EllipticFrame, AffineFrame, and Paraboloid3D — documented in the Primitives guide.
  • Attributed{V,A} and AbstractDetection — the value-plus-metadata composition pattern, documented in Design: Attributed{V,A}.
  • Correspondence types (Cspond, Csponds, ScoredCspond) and the endpoint-lift protocol — see the Correspondence API.
