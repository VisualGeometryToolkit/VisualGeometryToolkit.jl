Fundamental Matrix

RANSAC Problem

FundMatProblem is a type alias for MinimalSolveProblem{FundMat{T}, 7, T, ...} — a 2D-2D correspondence problem with the 7-point minimal solver and, for LO refinement, Levenberg–Marquardt on the 7-dof Bartoli–Sturm chart about the current F (signed Sampson residual).

VisualGeometryToolkitEstimation.FundMatProblem — Type
FundMatProblem(pairs; sampler=nothing, backend=NativeSolver())

Construct a FundMatProblem from 2D-2D point correspondences. See HomographyProblem for the input container, its :score prior and sampler.

FundMatProblem(pair::PoolPair{<:FundMat}; kw...) -> FundMatProblem

The pool-frame fundamental problem of a pool record: its correspondences (NormalizedImageFrame) verbatim. Its sample gate reads the scale-free tolerance on its normalized view, so it takes no coincident_tol. kw go to FundMatProblem.

Fitting Pipeline

VisualGeometryToolkitEstimation.find_fundmat — Function
find_fundmat(correspondences; threshold=3.0,
    max_trials=10000, min_trials=100,
    local_optimization=Irls{TLSShape}(),
    scoring=nothing, config=nothing)

Robust fundamental matrix estimation via 7-point RANSAC with MSAC scoring and least-squares-on-the-inliers local optimization. Every default shown is configs/default.toml's ([ransac], [pipelines.fundmat]); a keyword overrides.

Returns a RansacEstimate or nothing if fewer than 7 correspondences. iterations(result) is the number of trials (hypotheses drawn); test converged(result) before reading the model (see RansacEstimate).

Arguments

  • correspondences: as find_homography; a Csponds :score column is the per-match prior (PROSAC; uniform otherwise).
  • threshold: in PIXELS, as find_homography.
  • workspace: as find_homography, built with RansacWorkspace(FundMatProblem{Float64}, n_data[, T]).
  • local_optimization: default Irls{TLSShape}(), as find_homography.
  • the other keywords as find_homography.
