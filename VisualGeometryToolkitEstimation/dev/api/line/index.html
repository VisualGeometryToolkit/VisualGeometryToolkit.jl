Line Fitting

RANSAC Problems

Two RANSAC problem types for 2D line fitting, distinguished by their noise model:

VisualGeometryToolkitEstimation.LineFittingProblem — Type
LineFittingProblem{T} <: AbstractRansacProblem

Plain RANSAC problem for estimating a 2D line from points with per-point covariances.

Residuals are standardized: r_std[i] = (n⊤pᵢ + d) / √(n⊤Σᵢn), so all points contribute on a comparable scale regardless of their covariance shape.

Supports LO-RANSAC via refine!(ws, problem, θ, weights) (θ unread: a linear problem's step): the covariance-weighted line of fit_line with each point's weight wᵢ/σᵢ² — the local optimizer's robust weight times its inverse variance along the normal — seeded by the w-weighted total-least-squares normal. A zero weight drops the point.

Constructors

LineFittingProblem(pts::AbstractVector{<:Uncertain{<:Point2}})
LineFittingProblem(pts::AbstractVector{<:Point2})  # identity covariances

Solver Details

  • Minimal sample: 2 points (returns FixedModels{1, Line2D{T}})
  • Model type: Line2D{T} (Hesse normal form)
  • Residual: Standardized orthogonal distance
  • LO-RANSAC: refine!(ws, p, θ, weights) — the weights-weighted fit_line step, θ unread
VisualGeometryToolkitEstimation.InhomLineFittingProblem — Type
InhomLineFittingProblem{T} <: AbstractRansacProblem

Inhomogeneous line fitting: y = a + b·x, 2 parameters, scalar residual.

The simplest possible RANSAC problem for debugging and testing the covariance-aware pipeline. No standardization, no per-point covariances.

Model

  • SVector{2,T}: (a, b) where y = a + b·x
  • Residual: r_i = y_i - a - b·x_i (scalar, raw)
  • Residual DOF: 1
  • Model DOF: 2

LineFittingProblem uses Hesse normal form (Line2D{T}) with per-point covariance shapes (standardized residual). InhomLineFittingProblem is the inhomogeneous y = a + b·x form with errors only in y.

Robust Linear Least Squares

fit_linear is the robust coefficient vector x of y ≈ A·x (rows with gross outliers): a reweighted least squares under a loss shape at a multiple of the residuals' MAD scale, with optional fixed prior row weights — the scalar-residual sibling of fit_rotation.

VisualGeometryToolkitEstimation.fit_linear — Function
fit_linear(A, y[, prior]; loss, scale_multiple = nothing, max_iter, tol)
    -> FitResult{Vector{Float64}, LinearFitMetadata}

The robust coefficients x of y ≈ A·x (A an m × n matrix, y an m-vector), with a fraction of the rows gross outliers. A fit — it seeds itself with the prior-weighted least squares — iterating a reweighted least squares: residuals rᵢ = yᵢ − aᵢᵀx, the robust scale σ̂ = median|r| / √chisq_median(1) (the normal MAD scale, over the rows of positive prior weight), the weights of loss (an AbstractLossShape, e.g. HuberShape()) at width scale_multiple · σ̂, times the prior, and the weighted least squares.

  • prior — fixed non-negative row weights (a bootstrap's resampling counts, a previous fit's weights); a zero weight drops its row. Default all ones.
  • loss — the robust loss shape (default the TOML's, Huber).
  • scale_multiple — the width as a multiple of σ̂; nothing takes the shape's efficiency constant at codimension 1 (deploy's default; Huber's 1.345), which only an M-estimator (AbstractMEstimator) has: any other shape requires it (ArgumentError).
  • max_iter, tol — at most max_iter iterations after the seed; converged when one moves x by less than tol · max(1, ‖x‖∞) in the max-norm (defaults: configs/default.toml [fitlinear]). `maxiter = kmakesk + 1` weighted solves.

The least squares is a column-pivoted QR, so a column that no row with weight reaches (an unsupported basis function) gets a basic solution's value, not an error; drop such columns before the call when their value matters.

retcode is :converged, :max_iterations, or :degenerate when fewer rows keep a positive weight than there are columns; on exact data (every residual zero) the seed is returned, :converged. rms is the root mean square residual over the rows of positive prior weight; the metadata carries the weights, the residuals and σ̂ at the returned coefficients.

VisualGeometryToolkitEstimation.LinearFitMetadata — Type
LinearFitMetadata

FitResult metadata of fit_linear, all at the returned coefficients: weights, the loss's IRLS weight of every row times its prior weight; residuals, y − A·x; sigma, the robust noise scale σ̂ the final weights were computed at. They forward as properties: result.weights, result.residuals, result.sigma.
