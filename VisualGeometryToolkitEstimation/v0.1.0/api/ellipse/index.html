Ellipse Fitting

refine_ellipse fits an ellipse to points by minimizing the orthogonal distance. It starts from VisualGeometryToolkitCore's algebraic direct_ellipse unless a start value is supplied as init.

VisualGeometryToolkitEstimation.refine_ellipse — Function
refine_ellipse(points, init = direct_ellipse(points); max_iter = 100)
    -> FitResult{Uncertain{Ellipse}, EllipseFitMetadata}

The ellipse minimizing the summed squared orthogonal distance Σᵢ dᵢ² of the 2-D points to it, dᵢ the distance of point i to its foot point: the maximum-likelihood ellipse under isotropic Gaussian noise on the points. A Levenberg–Marquardt refinement from init (by default VisualGeometryToolkitCore's algebraic direct_ellipse) on the log-shape chart (ellipse_log_shape), which cannot leave the ellipses and is smooth at a circle.

The estimate carries the covariance of the log-shape chart vector, s²·(JᵀJ)⁻¹ with s² = Σdᵢ²/(n−5), J the Jacobian of the distances at the solution. retcode is the LM's (:converged, :max_iterations or :stalled). Throws ArgumentError for fewer than 6 points, or when the default start does not exist (direct_ellipse returns nothing).

VisualGeometryToolkitEstimation.EllipseFitMetadata — Type
EllipseFitMetadata{T}

FitResult metadata of refine_ellipse. The core carries the fitted ellipse — estimate is an Uncertain{Ellipse{T}, <:CovMat{5,T}} whose covariance is that of the log-shape chart (cx, cy, S₁₁, S₁₂, S₂₂) (ellipse_log_shape) — the LM's retcode and iterations, and rms, the root-mean-square orthogonal distance over the n points. Here:

  • s²::T: estimated residual variance, S/(n-5)
  • ν::Int: degrees of freedom, n - 5

Both forward as properties: result.s², result.ν.
