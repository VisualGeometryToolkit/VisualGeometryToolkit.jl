VisualGeometryToolkitEval.VisualGeometryToolkitEval — Module
VisualGeometryToolkitEval

The evaluation base of the visual-geometry stack: statistics (Stats), the codified cross-validation (Tuning, Evaluation), the stage/run-record framework (Experiments), rendering (Render), pool IO (Pools), the raw dataset readers (Datasets), the published-data catalog (DataArtifacts), the reproducible-figures contract (Reproduce) and the paper-project conventions (PaperProjects), with the artifact formats, the defaults of record and the driver CLI. Depends on VisualGeometryToolkitCore, VisualGeometryToolkitIo and the core estimator VisualGeometryToolkitEstimation (its loop and problems, for the composition evaluator) — never on a paper's scorer or optimizer package.

Each submodule's API is reached through it (using VisualGeometryToolkitEval.Pools); this module exports the submodules and the CLI.

VisualGeometryToolkitEval.Stats.bootstrap_ci — Method
bootstrap_ci(stat, rng, x; n_resamples, alpha) -> (lo, hi)

BCa (bias-corrected and accelerated) bootstrap CI of stat(x) via Bootstrap.jl — Shekhovtsov's scipy.stats.bootstrap(..., method='BCa') protocol. For a REAL sample the non-finite entries are dropped first and a constant sample returns its value as a degenerate interval. Any other element type is resampled as given (e.g. a scene-cluster bootstrap over per-scene error matrices, with stat reducing the resampled scenes). Fewer than 3 elements → (NaN, NaN) (BCa's jackknife needs them).

rng seeds the global Random stream before the Bootstrap.jl call (the library resamples from it and takes no rng), so a fresh seed per call keeps a run reproducible ON ONE JULIA VERSION: the resampling itself is Julia's task-local default stream, whose algorithm Julia does not fix across versions (record julia_version beside a reported CI). n_resamples and alpha default to configs/default.toml [metrics] (bootstrap_resamples, ci_alpha).

VisualGeometryToolkitEval.Stats.eligible_maa — Function

THE mAA@T of a set of pairs under the eligibility rule: the continuous AUC (VGC mean_average_accuracy) over the ELIGIBLE pairs, where a non-finite error (a run that yielded no model) scores 0 and stays in the denominator, and an ineligible pair (eligible[i] == false: no ground truth, or fewer valid correspondences than a minimal sample) is excluded. eligible = nothing treats every pair as eligible. NaN when no pair is eligible. T defaults to maa_threshold.

VisualGeometryToolkitEval.Stats.reference_scale — Method
reference_scale(s2) -> Float64

THE validation reference scale s0 = √median σ̂² over the FINITE entries of the per-pair inlier variances s2 — the scale every tuning window is positioned at. Throws on an input with no finite entry: a window cannot be placed without a scale, and a NaN scale would silently select nothing.

VisualGeometryToolkitEval.Stats.scale_bounds — Method
scale_bounds(s2, q) -> (ŝ_min, ŝ_max)

Robust scale extremes of a validation pool: √ of the q = (q_lo, q_hi) quantiles of the per-pair noise variances s2 (σ̂², e.g. gt_variance; non-finite entries are dropped). Restricting drawable validation pairs to σ̂² ∈ [ŝ_min², ŝ_max²] makes the plug-in ŝ(n) = √median σ̂² over ANY drawn subset lie in [ŝ_min, ŝ_max], for every n. The coverage window rule (Tuning.CoverageWindow, which carries q) and the validation-eligible mask are built from these bounds, so a windowed tuner's window provably stays on its grid. q has no default: it is a parameter of the tuning spec.

VisualGeometryToolkitEval.Stats.scene_mean — Method
scene_mean(stat, scene_errors) -> Float64

The equal-weight MEAN over scenes of each scene's stat (scene_errors iterates the scenes' value vectors); a scene whose statistic is not finite is skipped, and the result is NaN when no scene has one.

THE scene-level aggregation: a per-scene statistic weights scenes, not pairs, which is what a cross-validation split BY SCENE is asking for. isfinite is the right skip predicate for either statistic this takes — finite_median filters non-finite values first and so returns a finite value or NaN, while lower_median does not and can return ±Inf.

scene_mean_median_rows!(rows, method, xs, cols, scene_ranges; seed, ci_min = [metrics] ci_min_scenes)

VisualGeometryToolkitEval.Tuning.CoverageWindow — Type
CoverageWindow(q_lo, q_hi, log_margin, zeta_octaves)

The COVERAGE window of a native axis (outlier half-width, loss width): every native the scale-multiple window can request at any reference scale the validation pool can produce, [native(lo, ŝ_min/ζ)·e^{-m}, native(hi, ŝ_max·ζ)·e^{m}] with [lo, hi] the scale-multiple window, (ŝ_min, ŝ_max) = scale_bounds(s2, (q_lo, q_hi)), ζ = 2^zeta_octaves (the scale corruptions the run reads out at, 0 for none) and m = log_margin (log headroom so a request at the bounds sits strictly inside). TOML tag "coverage".

The name is the GUARANTEE, not the mechanism: the realized grid contains every native the window can request at any scale the pool produces, so a windowed free argmin provably cannot leave its grid. That is what the validation-budget mode needs, where 3500 draws share one sweep and each has its own ŝ(n).

q_lo == q_hi is legal and is the ONE-ANCHOR case: both sides anchor on the same √quantile(σ̂², q), and at q = 0.5 that is reference_scale(s2), so coverage { q_lo = 0.5, q_hi = 0.5, zeta_octaves = 0.0 } is the WINDOW-MATCHED grid — the native image of the scale-multiple window and nothing more. A tune has one reference scale, so this is the tuning case; a spread band is for the modes that have many. (It replaced a separate StandardizedNativeWindow rule, which was this rule with its band collapsed and was a distinct type only because the constructor forbade q_lo == q_hi.)

VisualGeometryToolkitEval.Tuning.WindowRule — Type
WindowRule

How an axis's window (lo, hi) is found: FixedWindow, StandardizedWindow, CoverageWindow, CenteredWindow. window(rule; context...) evaluates it; each rule takes only the context it needs and refuses a missing one.

Factored, a window is STATED or PLACED, and the placed ones differ only in their ANCHOR and how their endpoints leave it:

ruleanchorendpoints
FixedWindow—its own two native numbers
StandardizedWindow—the scale-multiple window verbatim
CoverageWindow(ŝ_min/ζ, ŝ_max·ζ), per sidethe window through native, ± margin
CenteredWindowa supplied native point÷/× factor

Note where ζ sits: it scales the ANCHOR, never the endpoints. A window whose anchor spreads is asserting that the scale could be anywhere in that spread — right for a ζ ladder or a budget sweep, wrong for a tune, which has ONE reference scale. Anchor spread is bought with the grid's resolution.

  • :configs — C1 a producing script reads no config of record; C2 it holds a data constant (a literal seed, name list, numeric table or range, data path); C3 a script names a config under configs/ that does not exist.
  • :provenance — P1 a producing script (with what it includes and launches) writes no provenance through the shared writer; P2 it keys no output by a run key; S1 a generator of the index has no stage runner.
  • :catalog — A1 DataArtifacts catalog_violations, once the catalog or Artifacts.toml binds an artifact (catalog_kinds are the project's own kinds).
  • :contract — Experiments contract_violations of every stage file.

A producing script is a .jl under scripts/ that runs stages, declares an output (reproduce: writes), is a generator of the index or calls a result writer. Opt out of one rule where the constant is justified with # paper-project: allow <RULE> <reason> (on the line or the line above for C2/C3; anywhere in the file for C1, P1, P2, S1); a reasonless opt-out is X1. Deferred violations of any rule go in allow (DataPolicyAllow(rule, file, match), match a substring of the violation's text); an entry matching nothing is reported STALE.
