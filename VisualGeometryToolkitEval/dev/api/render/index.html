API: Render

Figures and tables through PGFPlotsX.

Public names

VisualGeometryToolkitEval.Render — Module
Render

Figure and table rendering through PGFPlotsX: the panel record (PanelSpec), a paper's styling as one value (PaperStyle), the faceted-arm grammar (arm_style), the house axis style (HOUSE_AXIS_COMMON), the shared faceted group-plot emitter (open_faceted_groupplot) and the panel and table emitters (emit_miscal_faceted, emit_basin_faceted, emit_tuning_table), and the table-file helpers (fmt3, write_tsv, read_tsv).

The loss-family facet order, left to right, of every faceted figure and legend.

HOUSE_AXIS_COMMON

The common axis-option string every NEW (post-ACCV) panel starts from: no grids, plain-number tick labels on log axes, house fonts and legend style. Panel-specific options (labels, limits, modes) are appended after.

VisualGeometryToolkitEval.Render.PANELS — Constant
PANELS

The summary panels, keyed by id: (id, yfn, ylabel, log_y, y_spacing, y_minor_subdiv). y_spacing is the major-tick (labeled) gradation on a linear y-axis (NaN = off); y_minor_subdiv the number of minor ticks BETWEEN majors (0 = none). eR_mean is a legacy id: for E and F the metric is the imc POSE error max(Δrot,Δtrans); a homography's imc is the decomposition's rotation alone (VgtkCore pool_imc on an H pool), so an H panel overrides the label (build_axis(...; ylabel)).

VisualGeometryToolkitEval.Render.PaperStyle — Type
PaperStyle(; colors = Pair{String,String}[], rows = [], arms = Dict(),
           grid, zeta_x, zeta_med_y, zeta_maa_y, med_ylabel, maa_ylabel)

A paper's figure style, built once by the paper (accv2026 builds it from its palette, arm table and figure-style blocks) and given as the first argument of every renderer that draws arms or paper colours.

Fields:

  • colors::Dict{String,String}: colour NAME => hex "RRGGBB" — the paper palette (default_palette is the house base) plus every arm colour whose record carries a hex; emitted by paper_color_defs.
  • rows::Vector{Tuple{String,String,String,String,Bool}}: the summary-panel rows of build_axis, in legend order: (method key, display label, colour name, mark, dashed).
  • arms::Dict{String,NamedTuple}: the faceted-arm style records, arm_style_records — family, path, scale, label, colour, hex, marker, dashed, shade.
  • axes::NamedTuple: the paper's axis blocks of the faceted emitters — grid (the grid options spliced into the budget/basin/time panels; "" is the house rule, no grid), zeta_x (x block of the ζ panels), zeta_med_y (a function (ymin; ymax, ytick_spacing) -> String, the median row's y block), zeta_maa_y (the mAA row's y block), med_ylabel and maa_ylabel (the two rows' y labels).

A paper whose figures were frozen at an earlier style (the ACCV panels are byte-compared) supplies those exact blocks here; nothing in this package defaults to them.

VisualGeometryToolkitEval.Render.arm_style_records — Method
arm_style_records(probes, table) -> Dict{String,NamedTuple}

The faceted-arm style records of a paper, keyed by arm: one record (family, path, scale, label, color, hex, marker, dashed, shade) per arm_key => probe_instance pair of probes (one LO instance per deployed arm; ctor kwargs immaterial, the identity traits are type/variant-level), with table[arm_key] the paper-owned part, (color = …, [hex = …], [shade = …], [scale = …]): the colour NAME, optionally its hex (a PaperStyle defines it under that name), the arm's step on its family's light→dark colour ramp (shade, 1 = lightest; it fixes the within-facet legend/plot order) and an optional scale tag, which must agree with the strategy's scale_interface. family, path, label, marker and dashed (FixedScale ⇒ dashed) DERIVE from the probe's identity traits. Errors on a probe with unspecified identity traits (registry hygiene).

VisualGeometryToolkitEval.Render.budget_curves — Method
budget_curves(files; arms) -> (; budgets, med, maa, oracle_med, oracle_maa, outcomes)

The statistics of a budget cell from its per-scene budget files (the scene schema above), for each of arms and the oracle, at every LO checkpoint (budgets = the files' lo_counts; the oracle read off its dense batch grid at those budgets):

  • med — the mean over scenes of the per-scene finite median (Shekhovtsov's mean-median; a scene without a finite error is skipped);
  • maa — the eligibility-ruled mAA (eligible_maa) POOLED over every pair of every scene — every stored pool pair is eligible, a pair whose run left no model (non-finite error) scores 0.

Every file must carry the same count axes and every one of arms. outcomes[arm] is pair_outcomes at the last checkpoint (why runs fail).

VisualGeometryToolkitEval.Render.build_axis — Method
build_axis(style::PaperStyle, panel, data, tune::String, spec::PanelSpec; ylabel = "")

The PGFPlots axis of one (PANELS entry, tuning-criterion label tune): one curve per row of style.rows present in data (load_results). Every display option comes from spec; spec.xlabel === nothing is "Validation set size". ylabel overrides the panel's.

VisualGeometryToolkitEval.Render.color_defs — Function
color_defs(pairs; command = "definecolor") -> String

The colour-definition emitter: one \<command>{<name>}{HTML}{<hex>} line per name => "RRGGBB" pair, newline-separated (no trailing newline). command is "definecolor" or "providecolor" (idempotent; a host's own definition wins).

VisualGeometryToolkitEval.Render.default_palette — Method
default_palette() -> Vector{Pair{String,String}}

The house base palette (name => hex, ordered): the standing selector/ reference colors every paper starts from — RGB-primary "ours" hues (Jeffreys red e6194b, IG-Robust green 3cb44b, IG-MLE blue 4363d8), baselines chosen so none competes with Jeffreys red (RANSAC pastel pink ffb6c1, MSAC yellow ffe119, GaU cyan 42d4f4, MAGSAC++ orange f58231), and the medium-gray Oracle 808080. Per-arm FAMILY shades (Welsch greens / TLS oranges / GM purples — the faceted grammar's hue-= family rule) are paper-assigned on top of this base in the paper's PaperStyle; papers override or extend freely — this table is the documented default, not a constraint.

VisualGeometryToolkitEval.Render.emit_basin_faceted — Method
emit_basin_faceted(style::PaperStyle, bundle, out; row_label = "", succ, deploy,
                   exclude = Set{String}(), legend_name = "basinlegend",
                   panels = [(f, panel_title(f)) for f in FAMILY_ORDER],
                   minsucc = [render] min_success_for_cond_mean, seed_key = "seed",
                   rows = [:succ, :cond])

Emit the δ-perturbation basin faceted groupplot body to out from the ladder bundle (errs [pairs × nδ × nmethod], methods, deltas, refinable). rows selects the statistic per row, in order: :succ — success rate P(e≤succ°); :maa — mAA@succ° under the eligibility rule (eligible_maa: the refinable pairs are the eligible ones, a failed refit — stored as NaN — scores 0); :cond — conditional mean final error given success, masked below success rate minsucc. Success is recomputed at succ degrees; the seed_key method draws as the dashed reference (its success rate, mAA, or unconditional median per row). deploy/exclude/legend_name as in emit_miscal_faceted.

VisualGeometryToolkitEval.Render.emit_budget_faceted_curves — Method
emit_budget_faceted_curves(style::PaperStyle, out; row_label = "", budgets, med, maa,
                           med_ylabel, legend_name, deploy, xticks = nothing,
                           maa_ylabel = style.axes.maa_ylabel,
                           panels = [(f, panel_title(f)) for f in FAMILY_ORDER],
                           xlabel = raw"sample budget", xlog = true, rows = [:med, :maa],
                           oracle_med = nothing, oracle_maa = nothing,
                           oracle_label = "oracle")

The objective-faceted accuracy-vs-budget groupplot, from PRECOMPUTED per-arm curves (budget_curves for a budget cell's scene files; the PnP budget's own aggregation): med[arm] (median error, row label med_ylabel) and maa[arm] (mAA@10°) are vectors aligned with budgets; arms are keys of style.arms, and the grid options are style.axes.grid. xlog draws a log₂ budget axis with plain-number ticks at the given budgets (small budget grids such as 5…2000); the y ranges are derived from the curves. oracle_med/oracle_maa (aligned with budgets) draw the oracle reference line when given.

VisualGeometryToolkitEval.Render.emit_budget_time_panel — Method
emit_budget_time_panel(style::PaperStyle, out; row_label = "", budgets, maa, percall_us, legend_name,
                       xmax, xticks, maamax, panels = [(f, panel_title(f)) for f in FAMILY_ORDER])

The COMPUTE-EFFICIENCY companion of a budget panel: mAA (maa[arm], aligned with budgets, from budget_curves) against the cumulative LO time per pair [ms] — at checkpoint j, j × the arm's deterministic single-thread per-call time percall_us[arm] [µs] (one LO per pair per checkpoint). LO cost only: scoring, sampling and termination are shared and excluded (the caption must keep that scoping); the oracle runs no LO and has no curve. xmax / xticks / maamax are the panel's fixed axis constants. Every arm of maa must have a per-call time.

VisualGeometryToolkitEval.Render.emit_lo_timing_table — Method
emit_lo_timing_table(figdir; timedir, arm_rows, dataset_names,
                     rider_labels, filename = "table_lo_timing.tex")

Emit the LO per-call wall-clock table (<figdir>/<filename>) from the lo_timing_*.jld2 files under timedir. arm_rows is the ordered [(display_label, run_tag), …] row table; dataset_names maps dataset tag → display name; rider_labels maps a rider method Symbol (a non-:ig column of a run) → its arm label, nothing to skip. Each run's :ig column is keyed by the run tag itself (the timing driver's tags ARE the base names, so a roster extension cannot silently KeyError this emitter).

VisualGeometryToolkitEval.Render.emit_miscal_faceted — Method
emit_miscal_faceted(style::PaperStyle, sidecar, out; row_label = "", oracle, oracle_maa,
                    oracle_class = "E", ymin, deploy, ymax = 6, ytick_spacing = 1,
                    exclude = Set{String}(), legend_name = "miscallegend",
                    panels = [(f, panel_title(f)) for f in FAMILY_ORDER],
                    arm_filter = a -> true, rows = [:med, :maa])

Emit the ζ-miscalibration faceted groupplot body to out from the tuning artifact sidecar (zetas + evaluation): the per-arm evaluation_curves through emit_miscal_faceted_curves. Rows: median pose error (oracle FLOOR oracle) and mAA@10° (oracle CEILING oracle_maa); the median row's y block is style.axes.zeta_med_y(ymin; ymax, ytick_spacing), ymin its y floor (string, TeX-interpolated), ymax/ytick_spacing its ceiling and tick spacing (default 6°/1°). deploy wraps in a tikzpicture and leaves the legend to the host (\pgfplotslegendfromname{<legend_name>}); exclude drops arm keys from THIS render only; arm_filter restricts the roster (e.g. one scoring selector).

VisualGeometryToolkitEval.Render.emit_miscal_faceted_curves — Method
emit_miscal_faceted_curves(style::PaperStyle, out; zetas, med, maa, deploy, legend_name, rows,
                           oracle = nothing, oracle_maa = nothing,
                           oracle_class = "",
                           x_axis = style.axes.zeta_x,
                           med_axis = style.axes.zeta_med_y("0.4"),
                           maa_axis = style.axes.zeta_maa_y,
                           med_ylabel = style.axes.med_ylabel,
                           maa_ylabel = style.axes.maa_ylabel,
                           panels = [(f, panel_title(f)) for f in FAMILY_ORDER],
                           flat = Set{String}())

The objective-faceted ζ groupplot from PRECOMPUTED per-arm curves: med[arm] and maa[arm] are vectors aligned with zetas (NaN = masked point); arms are keys of style.arms, so family, mechanism order, label, color and marker all derive from the style. Arms in flat carry a single value that is drawn as a constant line across zetas (width-free controls). The oracle line spans zetas and is drawn only when oracle is given. Axis blocks default to the style's; supply other blocks for other error scales.

VisualGeometryToolkitEval.Render.emit_miscal_summary_table — Method
emit_miscal_summary_table(style::PaperStyle, path; tracks, stat = :med, exclude = Set{String}(),
                          arm_filter = a -> true, label = a -> arm_record(style, a).label)

The miscalibration summary table of a set of cells, from their sidecars (the same evaluations the faceted panels draw, so table and figure agree by construction). tracks = [(title, [(column_name, sidecar), …]), …]: one booktabs block per track, rows = the union of the track's arms of style in the faceted order, per dataset three columns — calibration, the deflation extreme and the inflation extreme of the ladder — with the best value per column bold (min for :med, max for :maa) and -- where a cell lacks the arm. Returns path.

VisualGeometryToolkitEval.Render.lo_us_per_call — Method

The mean warm LO wall clock per call [µs] of method column m of a budget result (anything carrying lo_ns_total / lo_calls_total per method — a budget engine's result or a run record read back from its sidecar); NaN when the column made no LO call. A pure accessor on persisted data.

VisualGeometryToolkitEval.Render.load_results — Method
load_results(path) -> Dict{Tuple{String,String}, SubDataFrame}

Load a results JLD2 carrying a summary DataFrame (the rows Evaluation.compute_method_rows emits — LocalOptimizationDoneRight's plotlosensitivity writes it as summary.jld2) and bucket that summary into one SubDataFrame per (method_key, tuning_criterion) for the PGFPlotsX renderer. Method key strips a trailing (median|mAA) suffix so the style rows' bare keys ("RANSAC") match.

Each sub-DataFrame is sorted by n so downstream rendering can index column vectors directly (s.nn, s.mean_med, s.lo95_mean_med, ...).

VisualGeometryToolkitEval.Render.miscal_summary_rows — Method
miscal_summary_rows(style::PaperStyle, sidecar; stat = :med, exclude = Set{String}(),
                    arm_filter = a -> true)
    -> (arms, rows, zetas)

The deployed evaluation of a miscalibration sidecar summarized at three points of its ζ ladder — the deflation extreme, calibration (ζ nearest 1) and the inflation extreme — per arm of style, in the faceted order (facet, then ramp step). stat is :med (finite median of the imc error, deg) or :maa (the eligibility rule, eligible_maa). rows[arm] = (deflation, calibration, inflation); zetas the three ζ values.

VisualGeometryToolkitEval.Render.open_faceted_groupplot — Method
open_faceted_groupplot(io; cols, rows, width, height, opts,
                       hsep = "6pt", vsep = "12pt", edge_labels = true)

Emit the shared groupplot preamble:

\begin{groupplot}[
  group style={group size=<cols> by <rows>, horizontal sep=<hsep>[, vertical sep=<vsep>,
    xticklabels at=edge bottom, xlabels at=edge bottom]},
  scale only axis, width=<width>, height=<height>,
  <opts[1]>,
  ...
  <opts[end]>]

opts are the remaining option LINES (each printed at 2-space indent; the last gets the closing ]). edge_labels=false drops the edge-tick lines AND the vertical sep (the 1-row paired layout).

VisualGeometryToolkitEval.Render.read_tsv — Method
read_tsv(path) -> Vector{Dict{String,String}}

The rows of a tab-separated table as dictionaries keyed by the header cells. Blank lines and # comment lines are skipped; the first remaining line is the header, and cells are strings (a row shorter than the header lacks the trailing keys).

VisualGeometryToolkitEval.Render.tuning_slice — Method
tuning_slice(path; axes, stage = :coarse) -> (; axes, xs, values, argmin)

The objective of a coarse-fine tuning artifact (Evaluation.save_coarse_fine_artifact) over the stage (:coarse or :fine) product grid, restricted to axes (one or two axis names) through that grid's argmin on every other axis: xs[i] the grid of axes[i], values the criterion's reported value (the mAA for a mean_average_accuracy criterion, else the objective) over them, argmin the index of the stage's argmin within the slice.

VisualGeometryToolkitEval.Render.write_article_preview — Method
write_article_preview(out_dir, panel_base, colordefs; legend_ref = "")

Write an article-class preview.tex in out_dir that \inputs the panel fragment panel_base (its filename WITHOUT .tex), then compile it to PDF with latexmk when it is installed. colordefs is the \providecolor block for the panel's colours; legend_ref names a legend to \ref below the panel.

VisualGeometryToolkitEval.Render.write_tsv — Method
write_tsv(path, header, rows; comments = String[]) -> path

Write a tab-separated table: each of comments as a #-prefixed line, then the header cells, then one line per row of rows (each cell through string), lines ended by \n. The parent directory is created. read_tsv reads it back.
