API: Reproduce

The reproducible-figures contract. See Reproducible figures.

Public names

VisualGeometryToolkitEval.Reproduce — Module
Reproduce

The reproducible-figures contract: paper_asset_graph (what a paper reads), read_reproduce_index (what REPRODUCE.md declares) and reproduce_index_violations (where the two disagree, plus generators that do not write their asset, static assets without provenance, and generated numbers re-typed in prose); and the regeneration's last stages: verify_assets and deploy_assets (a submitted asset is replaced only with sign-off), gather_numbers (the numbers file) and uncited_macros (numbers the paper defines but never cites).

VisualGeometryToolkitEval.Reproduce.VERIFY_REPORT — Constant
VERIFY_REPORT

The file name of the verify report verify_assets writes beside the renders: "verify.tsv".

VisualGeometryToolkitEval.Reproduce.IndexEntry — Type
IndexEntry

One row of a REPRODUCE.md asset index: the paper label it serves, the asset (project-relative path or glob), its kind (:generated, :static, or :invalid for an unrecognised kind cell), the generators (project-relative paths), the configs of record they read (project-relative; from an optional config column), the data it is generated from, the provenance note (required for :static), and the index line.

VisualGeometryToolkitEval.Reproduce.PaperAsset — Type
PaperAsset

One file the paper reads: path (relative to the project directory), kind (:tex for \input/\include, :graphics for \includegraphics, :data for a pgfplots/tikz data file), the referencing source file and line, the \labels of the enclosing float (inherited through \input), and whether the file exists.

VisualGeometryToolkitEval.Reproduce.PaperAssetGraph — Type
PaperAssetGraph

What a set of paper sources reads: the project directory root, the visited tex files (project-relative), every PaperAsset, every \label key, and the references whose target could not be resolved statically (a macro or #1 in the path) as (source, line, text).

VisualGeometryToolkitEval.Reproduce.ReproduceViolation — Type
ReproduceViolation

One breach of the reproducible-figures contract: a kind (see reproduce_index_violations), the subject (an asset, generator or macro), a human-readable message and a location (file:line).

VisualGeometryToolkitEval.Reproduce.assets_deployed — Method
assets_deployed(outdir, paperdir, names) -> Bool

Whether every rendered outdir/<name> is byte-identical to the paper's paperdir/<name>: a cheap done predicate of a deploy stage.

VisualGeometryToolkitEval.Reproduce.compare_fragments — Method
compare_fragments(new, old) -> NamedTuple

How a regenerated tex fragment new differs from the submitted old (texts): identical (byte for byte); same_numbers, every coordinates block equal in order (fragment_coordinates) and every argument-free macro definition equal (a numbers file); the block counts blocks_new and blocks_old; and max_abs_diff, the largest absolute coordinate difference over blocks of equal length (Inf when the block structure differs).

VisualGeometryToolkitEval.Reproduce.declared_inputs — Method
declared_inputs(generator_path) -> Vector{String}

The configs / inputs a generator declares, one per reproduce: reads <path> line in its source (in any comment syntax), project-relative.

VisualGeometryToolkitEval.Reproduce.declared_outputs — Method
declared_outputs(generator_path) -> Vector{String}

The outputs a generator declares, one per reproduce: writes <path-or-glob> line in its source (in any comment syntax), project-relative.

VisualGeometryToolkitEval.Reproduce.deploy_assets — Method
deploy_assets(outdir, paperdir, names; replace_submitted = false) -> Vector{String}

Copy each rendered outdir/<name> into paperdir when the paper has no copy or holds a different one, after verifying them all in one report (verify_assets writes a fresh outdir/verify.tsv first). A submitted copy that differs is replaced only with the author's sign-off on the difference the report states: replace_submitted = true signs off every asset of the call, a collection of names only those (per-asset sign-off, so one call deploys every asset and the report keeps every row). Without it the deploy is refused, as an error naming each differing asset and the report, and copies nothing. Returns the assets copied (an identical one is not copied).

VisualGeometryToolkitEval.Reproduce.fragment_coordinates — Method
fragment_coordinates(text) -> Vector{Vector{NTuple{2,Float64}}}

Every coordinates {…} block of a pgfplots fragment, in order, parsed to numbers: the quantitative content of a panel, for comparing a regenerated fragment with the submitted one independently of its formatting.

VisualGeometryToolkitEval.Reproduce.gather_numbers — Method
gather_numbers(fragments, out; generator, root, root_label = "<results_root()>") -> out

Write the paper's numbers file out from the generators' number-macro fragments (tex files): every argument-free macro of every fragment, one \newcommand{\<name>}{<value>} per line, sorted by name, under a header naming the generator and each fragment as <root_label>/<path relative to root> (no machine path). Never \providecommand: a macro the manuscript also defines must clash. A macro that two fragments define, and a fragment macro with arguments (a number is a value, not a template), are an ArgumentError.

Write out beside the generator's results, not into the paper: a submitted numbers file is replaced under the same sign-off as a figure, by deploy_assets.

VisualGeometryToolkitEval.Reproduce.macro_literal_violations — Method
macro_literal_violations(prose_files, macro_files; root, ignore = String[],
                         min_integer_digits = 3) -> Vector{ReproduceViolation}

Best-effort check that a number a generated macro file defines is not re-typed as a literal in the paper's prose: every argument-free macro of macro_files whose rendered value carries a number is searched for in the comment-stripped prose of prose_files, with number boundaries. A bare integer value is searched only from min_integer_digits digits (the default 3 skips the two-digit counts and percentages that coincide everywhere; 2 is strict and needs literal-ok marks). A line holding reproduce: literal-ok (in a comment) is exempt, as is any macro named in ignore.

VisualGeometryToolkitEval.Reproduce.paper_asset_graph — Method
paper_asset_graph(tex_files; root = dirname(first(tex_files)), search_dirs = String[]) -> PaperAssetGraph

Every file a paper reads, found by following \input/\include/ \subfile/\includestandalone (recursively), \includegraphics (with the \graphicspath directories and the default extensions tried in LaTeX's order), and pgfplots/tikz data files (\addplot table {file}, \pgfplotstableread{file}, \pgfplotstabletypeset{file}). Paths resolve against the directory of the top-level file, then against each of search_dirs in order (the compile directory and the TEXINPUTS of a build run elsewhere, e.g. ["paper"] for a main.tex in paper/src/ built from paper/ that writes \input{src/sec/intro}; a relative entry is relative to root), and are reported relative to root (the project directory). Graphics try the \graphicspath directories before search_dirs. Comments are ignored; a reference whose path holds a macro or a # parameter is recorded in unresolved, not guessed.

VisualGeometryToolkitEval.Reproduce.read_reproduce_index — Method
read_reproduce_index(path) -> Vector{IndexEntry}

The asset index of a REPRODUCE.md: every markdown table whose header has the columns asset, kind and generator (case-insensitive; label, config, data and provenance are read when present, any other column is ignored). A cell's backticked tokens are its values (several assets in one row expand to one entry each); a row without backticks uses the cell text. kind is the first word of its cell: generated or static.

VisualGeometryToolkitEval.Reproduce.reproduce_index_violations — Method
reproduce_index_violations(project_dir; papers, index = "REPRODUCE.md", check_literals = true,
                           ignore_macros = String[], min_integer_digits = 3,
                           require_config = false, search_dirs = String[]) -> Vector{ReproduceViolation}

The reproducible-figures contract of a paper project, as a list of violations (empty = compliant). papers are the top-level tex files and index the REPRODUCE.md, both relative to project_dir; every asset path in the index is project-relative. search_dirs (project-relative) are the directories a reference that does not resolve against a paper's own directory is looked up in (paper_asset_graph): the compile directory of a build run outside the paper's directory. Violation kinds:

  • :unindexed_asset — the paper reads a file no index entry covers
  • :missing_asset — the paper reads a file that does not exist
  • :unresolved_reference — a reference whose path is not static (macro, #1)
  • :unreferenced_entry — an index entry the paper does not read (stale row)
  • :invalid_kind — a kind other than generated / static
  • :no_generator — a generated entry naming no generator
  • :missing_generator — a named generator does not exist
  • :generator_does_not_write — no named generator writes the asset: none declares it (reproduce: writes <glob>) and none mentions its file name
  • :static_without_provenance — a static entry with no provenance note
  • :no_config — with require_config = true, a generated entry naming no config of record (a config column cell)
  • :missing_config — a named config does not exist
  • :generator_does_not_read_config — no named generator reads the config: none declares it (reproduce: reads <path>) and none names its file
  • :label_mismatch — the entry's label is a \label of the paper, but not of the float the asset sits in
  • :macro_literal — a number a generated macro file defines, re-typed as a literal in the prose (macro_literal_violations, with ignore_macros and min_integer_digits); off with check_literals = false
VisualGeometryToolkitEval.Reproduce.tex_macro_values — Method
tex_macro_values(path) -> Vector{Pair{String,String}}

The argument-free macros a tex file defines (\newcommand, \renewcommand, \providecommand, \def), as name => value.

VisualGeometryToolkitEval.Reproduce.uncited_macros — Method
uncited_macros(numbers_path, papers; root = dirname(first(papers)), search_dirs = String[],
               allow = Dict{String,String}()) -> Vector{String}

The macros the numbers file numbers_path defines that the paper does not cite: the tex files the paper reads are the ones paper_asset_graph visits from the top-level papers (with root and search_dirs as there), comments ignored, the numbers file itself excluded; a citation is the macro name not followed by a letter (\nA is not cited by \nAb). The allow table (macro name without backslash => reason) exempts a macro; an allow entry naming no macro of the file is returned as stale allow: <name>. Sorted. A paper that does not read numbers_path is an ArgumentError.

VisualGeometryToolkitEval.Reproduce.verify_assets — Method
verify_assets(outdir, paperdir, names) -> Vector{NamedTuple}

Compare each rendered outdir/<name> with the submitted paperdir/<name> and write the report outdir/verify.tsv (VERIFY_REPORT): one row per asset with asset, submitted, identical, same_numbers, blocks_new, blocks_old, max_abs_diff, bytes_new and bytes_old. A .tex asset is compared by its numbers as well as its bytes (compare_fragments); any other asset by its bytes. Each verdict is printed. A missing render is an error; a missing submitted copy is reported (submitted = false), not an error. Returns the rows.
