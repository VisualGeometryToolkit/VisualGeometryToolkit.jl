API: the top module

The driver command line, the artifact formats and the path of the defaults of record.

Public names

VisualGeometryToolkitEval.ARTIFACT_FORMATS — Constant
ARTIFACT_FORMATS

The format version this package writes and reads, per artifact kind (:pool, :pool_residuals, :pool_samples, :pnp_pool, :tuning), with the change the version introduced and the remedy for an older file. The file key is "<kind>_format"; an absent key is version 1.

VisualGeometryToolkitEval.DEFAULTS_PATH — Constant

The defaults of record (configs/default.toml).

VisualGeometryToolkitEval.cli_option — Method
cli_option(args, key[, default])

The string value of --key=value in args. With default, the default when the option is absent; without it, the option is REQUIRED and its absence throws.

VisualGeometryToolkitEval.start_output_flush! — Method
start_output_flush!(; interval = 2) -> Timer

Flush stdout and stderr every interval seconds for the rest of the session (idempotent: a second call returns the running timer). The one flusher of every driver, GPU drivers included — it installs no logger type.

Internals

These names are not public; they are listed for contributors.

VisualGeometryToolkitEval._artifact_format — Method

The format version an open JLD2 file f declares for kind (absent key = 1).

VisualGeometryToolkitEval._check_artifact_format — Method
_check_artifact_format(path, kind)

Refuse path unless it declares the current kind format (ARTIFACT_FORMATS): an ArgumentError naming the file. Every reader of a kind artifact calls this before reading anything else.

VisualGeometryToolkitEval._config_default — Method
_config_default(table, key)

The default key of [table] (a dotted path, "pool.phototourism") in configs/default.toml. Throws a KeyError naming a missing table or key.

VisualGeometryToolkitEval._save_artifact — Method
_save_artifact(path, kind; keys...) -> path

The writer of a kind artifact: keys to path (JLD2), stamped <kind>_format at the current version. A key named like the stamp is refused.
