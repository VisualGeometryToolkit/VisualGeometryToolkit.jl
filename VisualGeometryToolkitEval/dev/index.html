VisualGeometryToolkitEval

VisualGeometryToolkitEval is the evaluation package of the VisualGeometryToolkit stack. It holds what the stack's research projects share when they benchmark robust estimators: statistics, a codified cross-validation (CV), an experiment framework, figure renderers, scoring-pool input and output, raw dataset readers, and an evaluator that composes a RANSAC scorer with a local optimizer (LO).

Installation

using Pkg
Pkg.add("VisualGeometryToolkitEval")

The package requires Julia 1.12 or later. It depends on VisualGeometryToolkitCore, VisualGeometryToolkitIO and VisualGeometryToolkitEstimation.

The modules

Each module's names are imported from it, for example using VisualGeometryToolkitEval.Pools: load_pool. The top module exports the modules and the driver command line (cli_option, start_output_flush!).

ModuleWhat it holds
Statsfinite and lower medians, the validation reference scale, the mean average accuracy (mAA), bias-corrected and accelerated (BCa) bootstrap intervals, means of per-scene medians and the seed derivation
Tuningthe CV specification: grids, window rules, objectives, scene splits and unit samplings, budget draws, schemes, the [tuning] TOML parser and the tuning artifact
Evaluationthe coarse-to-fine search of every CV, the bootstrap tuning harness and the composition evaluator
Experimentsthe stage runner, run keys and run records, provenance, and the data layer of a paper project
RenderPGFPlots figures and tables in the house style
Poolsthe scoring pool, its residuals, and the perspective-n-point (PnP) pool file
Datasetsraw readers of PhotoTourism, HEB, RoMa and SuperPoint+LightGlue correspondences, and of the depth-validated stereo datasets ETH3D, ScanNet1500, KITTI and 7-Scenes
DataArtifactsa paper project's published input data as Julia artifacts
Reproducethe reproducible-figures contract of a paper
PaperProjectsthe paper-project conventions: one check and one template

VisualGeometryToolkitEval — Module
VisualGeometryToolkitEval

The evaluation base of the visual-geometry stack: statistics (Stats), the codified cross-validation (Tuning, Evaluation), the stage/run-record framework (Experiments), rendering (Render), pool IO (Pools), the raw dataset readers (Datasets), the published-data catalog (DataArtifacts), the reproducible-figures contract (Reproduce) and the paper-project conventions (PaperProjects), with the artifact formats, the defaults of record and the driver CLI. Depends on VisualGeometryToolkitCore, VisualGeometryToolkitIO and the core estimator VisualGeometryToolkitEstimation (its loop and problems, for the composition evaluator) — never on a paper's scorer or optimizer package.

Each submodule's API is reached through it (using VisualGeometryToolkitEval.Pools); this module exports the submodules and the CLI.
