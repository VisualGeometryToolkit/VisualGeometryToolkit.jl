Serialization

The JSON hooks are methods of JSON.jl's lower and lift; the Serialization guide describes them and the format. The docstrings here are the helpers behind them.

VisualGeometryToolkitFeatures.LogicalDim — Type

Logical dimensions (pixel exponent ≠ 0): counts, densities. Snap to Int when integer-valued.

source
VisualGeometryToolkitFeatures.PhysicalDim — Type

Physical dimensions (pure length): always serialize as Float64.

source
VisualGeometryToolkitFeatures.ScalarOrQuantity — Type
ScalarOrQuantity

The type of a JSON value that holds either a plain number or a quantity: an alias of Number, since a FlexUnits quantity is a Number. Read one with JSON.lift(ScalarOrQuantity, x): a number comes back as it is, and a {"value": …, "unit": …} object comes back as a quantity in that unit.

julia> using JSON, VisualGeometryToolkitCore

julia> import VisualGeometryToolkitFeatures as VgtkFeatures

julia> JSON.lift(VgtkFeatures.ScalarOrQuantity, 5)
5

julia> JSON.lift(VgtkFeatures.ScalarOrQuantity, JSON.parse("""{"value": 2.5, "unit": "mm"}""")) == 2.5mm
true

julia> JSON.json(2.5mm)
"{\"value\":2.5,\"unit\":\"mm\"}"

Public, not exported.
